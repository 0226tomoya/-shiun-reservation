# shiun ラインナップ動画 編集ガイド

わむうチャンネルの shiun ラインナップ動画（A〇〇）を、実際の編集データ（FCPXML）と完成動画を突き合わせて分析し、同じ型で再現できるようにまとめたもの。

- 正解データ: **A19 shiun 26 Fall 2nd Collection**（[完成動画](https://youtu.be/KcpjBQPnDMc)、プロジェクト「本編」1570.5 秒）
- 比較データ: **A23 shiun 26 Fall 1st Collection**（[完成動画](https://youtu.be/uMARBnCQD_Y)、公開版はプロジェクト「靴なし」1533.9 秒）

| ファイル | 中身 |
|---|---|

| `PASTE_DATABASE.md` | Paste データベース全体（通常動画用テンプレのピンボード 46 件と、2025 年 4〜6 月のコピー履歴 909 件）の解析と、ラインナップとの使い分け |

YouTube のチャプターは「OP / 商品名 / 身長別比較N / … / ED」。FCP 側にもチャプターマーカーを打つ。

### 商品区間の型

1. **アイキャッチ（1.9 秒）**: SE「決定ボタンを押す32」に合わせて、ルック写真を大きく寄せ、フィルムルックの調整レイヤーを 2 枚重ねる。中央にコレクション名。パーツ: `S13`
2. **商品紹介イン（4〜7 秒）**: 左右に分割した写真（拡大 1.6、x ±44）の中央に商品名。単品の時は、左に商品写真、右にぼかしたモデル写真を置く。パーツ: `S08`（2 商品）、`S14`（単品）
3. **トーク**: ラックに商品を掛け、わむうは画面の右 1/3 に立つ。左上に商品名ラベルを出し続ける（メインのカットごとに貼り直す）。パーツ: `S09`、`F01`〜`F03`
4. **B-roll ブロック**: 右上に `Material` / `Design` / `Silhouette` / `Detail` / `Wash` / `Color` のラベル、下中央に字幕。写真を大きく寄せたもの、置き撮りを −3° 傾けたもの、手持ち撮影、左右分割を混ぜる。パーツ: `S10`、`S11`、`S15`、`S05`
5. **締め**: 字幕「数には限りがございますので、ぜひお早めにご検討ください」
6. **身長別比較**（2〜3 商品ごと）。パーツ: `S12`

## 3. 構図（わむうの位置）

A19 は 4K のカメラ 1 台で撮影している。メインの上（lane 1）に調整レイヤー（Paste「基本 / adjustment Layer」= `~/Titles/Adjustment Layer`）を置き、その変形（拡大と位置）でパンチインして寄り引きを作る。同じ構図は商品区間ごとに約 90 秒続け、区間が変わるときに Tight と Mid/Wide を切り替える。

| プリセット | 拡大 | 位置 | 使いどころ |
|---|---|---|---|
| Wide | 1.05 | -0.06, -2.54 | ラック全体とわむうの全身。商品を手に取る・指すとき |
| Mid | 1.21 | 9.44, 1.85 | 膝上。通常のトーク |
| Tight | 1.82〜1.86 | 17.0, -24.7 | 上半身。x を 24 / 35 / 60 に振って構図を変える |
| OP | 1.92 | -7.46, -29.47 | 冒頭の名前カードとトーク |

- **わむうは常に画面の右 1/3**（x がおよそ 60〜72%）。左 1/3 にラック（掛けた商品）が来るようにし、左上の商品名ラベルがわむうに被らないようにする。
- A23 は全身カメラとバストカメラの 2 台で、マルチカムのアングル切替で寄り引きを作っている（調整レイヤーの拡大はほぼ 1.15 で固定）。

| コレクション名 | Basic Title | Masqualero 40 白、2 行（名前と発売日） | 位置 -957.0, 486.0 / 拡大 0.9 | 左上の角 |
| 商品名ラベル | Basic Title | Masqualero 35（商品名）+ 18（色・サイズ） | 位置 -849.6, 444.0 / 変形 -0.94, 0 | 左上 |

## 5. 身長別比較（S12）

- 全画面に背景画像 `特殊アイキャッチ・背景等/2サイズ.png` を敷く。
- 右半分にモデル動画を 2 本並べる（拡大 1.13〜1.15、x ≒ -5 と 52、左はクロップ）。どちらにも **基本3D（回転 -3、調整 1 1.02）** を当て、顔は **センサー（Blur、Amount 0.5、Radius 300）** で隠す。
- 左上に身長と体重（`158cm 55kg`、Masqualero 70、olive `#53594A`）。動画の上にはサイズ記号（`XS` / `S` / `M`、Masqualero 50、olive）。
- 左側にサイズ表を置く。複合クリップ「身長別比較 クリップ」を拡大 0.8 で配置する。罫線は単色ジェネレーターを幅 0.001 まで潰して作り、文字は Hiragino Mincho W3 20、olive。
- 左下に商品名（Masqualero 35、olive、拡大 0.6）、右下に「色味はshiunオンラインストアの画像をご参照ください」。
- 1 人 9.6 秒 × 5 人（158/55、165/50、164/58、167/50、170/54）。

## 6. B-roll とエフェクト

| 手法 | 設定 | 使いどころ |
|---|---|---|
| 傾き | 基本3D 回転 -3 / 調整 1 1.02 | 置き撮り（E1_*）や手持ち撮影の一部。わずかに傾けて動きを出す |
| 写真ズーム | MP_テロップパック「拡大」（速度 0.02）＋ 拡大 2.7〜5.2 | 商品写真（SNS用高画質）に寄って素材感を見せる |
| 左右分割 | 左: 変形 -41.9, -6.4 / 拡大 1.23、右: 変形 39.9, 0 / 拡大 1.06、両方クロップ | 手持ち撮影 2 本を並べる |
| パンチイン | B-roll の上に調整レイヤー、拡大 1.07〜1.55 | 素材自体は触らずに寄る |
| フィルムルック | 調整レイヤー A: 色補正（露出ハイライト 0.675）+ プリズム 3 + ブルーム 0.0931、調整レイヤー B: プロジェクタ + ビネット + ノイズを追加 | OP のティーザーとアイキャッチ |
| ED 一覧 | 商品写真を横に並べ、商品名を拡大 0.6・y -35.5 で横一列 | ED（S16） |

使っているプラグインとテンプレート: **MP_テロップパック**（フェードイン / フェードアウト / 拡大 / フラッシュ 1）、**Adjustment Layer**（`~/Titles` 版と `共有用_Titles` 版の 2 つ）、**KAMAKEN ズームツール**（A23）。これらが入っていない Mac では、該当部分が赤く（欠落）表示される。

## 7. 音

- BGM: Epidemic Sound「See You in My Dreams - William Claeson」をループ。音量は **-17dB**、トークのない区間（ティーザー、カウントダウン）だけキーフレームで **+8dB**。
- SE: `SE/決定ボタンを押す32.mp3` をアイキャッチと ED ラインナップの頭に入れる。
- 声: ピンマイク音声（調整済み）を、マルチカムの音声アングルに設定する。小さい箇所だけ +7〜12dB。

## 8. 色味（A19 が正解）

A19 で測った完成画面の特徴は次のとおり。

- 暖色寄りのグレー（白壁は RGB でおよそ 172 / 170 / 160、Lab の b ≒ +4.4）
- 彩度は低め（平均の彩度 5.2）
- **ハイライトは 228 付近で頭打ち**（白飛びさせない）
- **黒はしっかり締める**（1% 点で RGB 4 / 4 / 2）

### 手順 1: A19 の調整レイヤーをそのまま使う

パーツ集の `F01`〜`F03` にある lane 1 の調整レイヤーには、A19 で 189 回使われた「カラー調整」がそのまま入っている。これをメインカメラの上にコピーし、尺を伸ばす。撮影条件が A19 と同じ（同じスタジオ、同じカメラ設定）なら、これだけでほぼ同じ色になる。

### 手順 2: 素材が違うときは、合わせ込み用の LUT を作る

素材によって元の色が変わるので、A19 の基準値に寄せる LUT を素材ごとに作る。

```bash
# 素材の代表カットを数本（動画のままでも可。均等に 24 コマ抜き出して使う）
python3 editing/tools/look_match.py lut editing/reference/A19_look.json \
    out/A27_main_to_A19.cube  素材/メインカメラ.mp4  素材/B-roll_置き.mp4  --strength 0.8

# 確認用に、左右比較の画像を作る（左: 元 / 右: 適用後）
python3 editing/tools/look_match.py apply out/A27_main_to_A19.cube 素材/still.png out/preview.jpg

# 数値で基準と比べる
python3 editing/tools/look_match.py stats editing/reference/A19_look.json 素材/still_after.png
```

FCP では、次の順に重ねる。

1. メインカメラの上（lane 1）に調整レイヤーを置き、**カスタム LUT** エフェクトで上の .cube を読み込む。
2. その上で、A19 の「カラー調整」は外すか弱める（LUT と二重に掛けない）。
3. B-roll は、カメラや場所ごとに別の LUT を作り、B-roll 側の調整レイヤー（lane 4〜5）に当てる。

- `--strength` は 0.6〜0.9 から試す。1.0 だと統計どおりに強く寄りすぎることがある。
- LOG 素材は、メーカーの変換 LUT で Rec.709 にしてから使う。
- 検証: A19 の画面をわざと青かぶり・黒浮き・低コントラストにした画像から、この方法で A19 の数値まで戻ることを確認済み（中間の明るさ 63.6 → 59.2、基準は 58.4）。

## 9. パーツ集の使い方

1. FCP で「ファイル → 読み込む → XML…」から `components/shiun_lineup_parts_A19.fcpxml` を開く。イベント「shiun 編集パーツ」の中に「パーツ集_本編」ができる。
2. ギャップが 20 個並んでいて、それぞれの頭にマーカー（`S01 OP 名前カード…` など）がある。必要なシーンの接続クリップをまとめてコピーし、本編に貼る。
3. 素材の画像や動画はオフラインになるので、「ファイル → 再接続」で今回の素材に差し替えるか、テロップと調整レイヤーだけを使う。
4. 別の動画の XML からパーツを作り直すときは、次を実行する。
   ```bash
   python3 editing/tools/extract_components.py 新しい.fcpxml 本編 scenes.json out.fcpxml
   ```

## 未確認のこと

- Paste の AI 用テンプレ（41 パーツ）は照合済み（`PASTE_CATALOG.md`）。Paste データベースも解析済み（`PASTE_DATABASE.md`）。「AI編集関連データ」の FCP ライブラリは、まだ受け取っていない。
- 「カラー調整」の中身は Apple 独自の形式で、数値に戻せない。そのため、XML ごとコピーする方法（手順 1）と、統計から LUT を作る方法（手順 2）の 2 本立てにしている。
- 完成動画は、YouTube のストーリーボード（320×180 を約 10 秒おき）で照合した。細かいアニメーションのタイミングは、XML の値を正とする。
