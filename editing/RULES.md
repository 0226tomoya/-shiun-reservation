## 型（A19 の実測。指摘 2・3 を受けて測り直したもの）

- インサートは「続いたかたまり」で入れる: かたまりの長さは中央値 16.4 秒（最長 75 秒）、かたまりの間のトークは中央値 15.5 秒
- 字幕 3 本を 1 つのかたまりにし、字幕の間（編集点 1 つ分）もインサートは切らない
- 字幕のない B-roll にはセクションラベルを付けない。同じ語が続く間はラベル 1 本（最長 30 秒）
- 紹介イン・名前カード・OP のモンタージュ・価格・ED の一覧・発売日も、長さは型の秒数前後で、終わりを編集点に合わせる
- 価格表示はインサートのかたまりの終わりからそのまま続けて出す（間にトークが一瞬見えないように）
- 動画インサートは素材の長さを超えて使わない

## 渡す前のチェック（全部通ってから渡す）

```
python3 -I tools/validate_fcpxml.py EDIT.fcpxml          # FCP で開けるか（DTD）
python3 -I tools/qa_timing.py EDIT.fcpxml 本編 -v         # フレーム・編集点（合計 0 件）
python3 -I tools/fcpxml_flatten.py EDIT.fcpxml 本編 FLAT.json
python3 -I tools/evaluate_lineup.py FLAT.json             # 型との一致（採点）
python3 -I tools/qa_lineup.py FLAT.json                   # 重なり・使い回し・空き
```
