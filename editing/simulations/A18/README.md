# シミュレーション: A18（shiun 26 Summer 1st Collection）を A19 の型で再現する

- 材料: A18 の編集データ（`A18_shiun summer1st ラインナップ.fcpxmld`、プロジェクト「本編」1631.36 秒）と完成動画（Dropbox の mp4、1920×1080 59.94p、1631.36 秒、YouTube の [2avOFva-G7M](https://youtu.be/2avOFva-G7M)）
- 型: A19（26 Fall 2nd）から抜き出した役割別のテロップ（`components/role_templates_A19.fcpxml`）と、README の配置ルール

## やったこと

1. A18 の全テロップ 391 本を役割（字幕、商品名ラベル、セクションラベル、身長別比較の各パーツなど）に自動で分類した。分類できなかったものは 0 本。
2. 各テロップの**内容（文字・時刻・レーン）だけを残し、書式と位置は型から作り直した**（`tools/build_lineup.py restyle`）。結果は `A18_型で再構成_字幕35.fcpxml` として FCP に読み込める。
3. 作り直したものと実際の A18 を 1 本ずつ比べた（`tools/compare_titles.py`）。
4. 完成動画のフレームに、型から計算した位置を重ねて目で確認した（`overlay_型の位置と実際.jpg`）。
5. カットのテンポ、寄り引き、BGM、色を比べた。

### 型との違い（A18 が A19 と違うところ）

- **字幕のサイズ**: A18・A23 は Klee **35**、A19 は **32**。**今後は 32 が標準**（確認済み）。A18 との差 75 本は、旧設定との違いであって型の誤りではない。
- **撮影**: A18 は**座って話す** 2 カメラ構成（A23 と同じ）。寄り引きは、調整レイヤーの拡大 1.27 / 1.15 / 1.33 で作っていて、A19 の立ち撮り用プリセット（1.05 / 1.21 / 1.82）はそのままでは使えない。わむうが画面の右寄り、ラックが左という配置は同じ。
- **ED 一覧の商品名の高さ**、**サイズ比較の商品名のサイズ**、**強調の太さ**（A18 は Klee Demibold 50、A19 は Klee Medium 50）は、動画ごとに手で調整している。

構成は型どおりだった: OP（ティーザー → 左上コレクション名 → 字幕 → カウントダウン 7.mp4）→ 商品 5 つ（間に身長別比較 4 回）→ ED。

### 色

白壁の色で比べた結果（内容に左右されない基準）は次のとおり。

| | L（明るさ） | a | b（黄み） |
|---|---|---|---|
| A19（正解） | 69.6 | −0.79 | **+5.3** |
| A23 | 69.7 | −0.36 | +5.8 |
| A18 | 67.8 | +0.62 | **+3.0** |

A18 は A19 より、少し暗く、黄みが弱く、わずかにマゼンタ寄り。A18 → A19 の LUT（`A18_to_A19.cube`）を作って当てると、壁と肌が A19 の暖かいグレーに寄った（`lut_新方式_白壁合わせ.jpg`）。

最初の方式（明るさの分布全体を合わせる）では、A19 の黒い服に引っ張られて、暗く締まりすぎた（`lut_旧方式_分布合わせ.jpg`）。そのため、`look_match.py` の既定を**黒点・白壁・白点の 3 点で合わせる方式**（`--mode anchors`）に変えた。

## 結論

- **テロップの型は、A18 でもそのまま使える。** 字幕のサイズを動画に合わせれば、92.6% が見た目で同じになる。残りは、画像の大きさに合わせた手調整（ED の高さ、サイズ比較の商品名、特殊な字幕の位置）。
- **寄り引きのプリセットは撮影の形（立ち / 座り、1 カメ / 2 カメ）ごとに用意する必要がある。** 共通しているのは、わむうが右、ラックが左という配置。
- **色は、白壁を基準にした LUT で A19 に寄せられる。** グラフィック（身長別比較の背景や表）には当てず、カメラ映像の上の調整レイヤーにだけ当てる。

## 再実行

```bash
python3 editing/tools/build_lineup.py templates A19.fcpxml 本編 editing/components/role_templates_A19.fcpxml
python3 editing/tools/build_lineup.py restyle editing/components/role_templates_A19.fcpxml A18.fcpxml out.fcpxml --subtitle-size 35
python3 editing/tools/fcpxml_flatten.py A18.fcpxml 本編 actual.json
python3 editing/tools/fcpxml_flatten.py out.fcpxml 本編 sim.json
python3 editing/tools/compare_titles.py actual.json sim.json --detail
```
