# Paste データベース（Paste_database_20261006.zip）の中身

Mac の Paste アプリのデータベースを丸ごと解析した結果。ラインナップ用の現行テンプレ（AI 用テンプレ、`PASTE_CATALOG.md`）とは別に、**わむうチャンネルの通常動画用テンプレのピンボード**と、**2025 年 4〜6 月に FCP でコピーした履歴**が入っていた。

| 中身 | 件数 | 時期 |
|---|---|---|
| `db.sqlite`（本体） | アイテム 48 件（FCP 46、テキスト 2）、ピンボード 11 個 | 作成 2025-06-26〜07-15、最終更新 2025-09-29 |
| `backup/2025-06-16/Paste.db` | クリップボード履歴 1,521 件（うち FCP 1,008 件、中身を読めたのは 909 件） | 2025-04〜06 |
| `_EXTERNAL_DATA` | 大きいデータの外部ファイル 152 個 | – |

FCP のデータは、FCP 独自のクリップボード形式（NSKeyedArchiver の中に Motion の ozml）で保存されている。これを解読して、タイトルの文字、フォント、サイズ、位置、プラグイン、フィルタ、効果音を取り出した。

## 2. ラインナップ動画で使っているもの・いないもの

ラインナップの本編（A19・A23）で、Paste DB から直接使っているのは次の 4 つだけ。

- **adjustment Layer**（メインカメラの寄り引き、B-roll のパンチイン）
- **ベタ塗り**（サイズ表の罫線）
- **BGM**（同じ複合クリップ）
- **ED**（同じエンディング動画）

テロップ類は、すべて AI 用テンプレ（Masqualero / Klee、`PASTE_CATALOG.md`）に置き換わっている。

一方、A23 と同じライブラリにある**縦型ショート**（「COW LEATHER LOAFER」「靴以外」、1080×1920）では、Paste DB のパーツを使っている。

| ショートで使っているもの | 回数 |
|---|---|
| ズームレイヤー（KAMAKEN ズーム 01） | 1 |
| クリック1回（マウス・シングルクリック） | 6〜7 |
| 字幕 Klee 28（位置 0, -433） | 50〜109 |
| 強調 Klee 40 ＋ フェードイン＋ドロップシャドウ＋フラッシュ 1 | 1 |
| ショート〆（締めの動画） | 3 |
| BGM: Epidemic Sound「Cherry Blossom」「Bumfuzzle」 | 各 1 |

ショートの字幕は、まず**文字起こしから自動で作った字幕のプロジェクト**（「靴以外_文字起こし用_normalized_テロップ」、YuGothic 30、162 本、位置 0, -433）を作り、それをショート用の Klee 28 に置き換えて使っている。

## 4. 編集するときの使い分け

| 作る動画 | 使うテンプレ |
|---|---|
| shiun ラインナップ（A〇〇）・LOOKBOOK・サイズ比較 | AI 用テンプレ（`PASTE_CATALOG.md`）＋パーツ集（`components/shiun_lineup_parts_A19.fcpxml`）。Paste DB からは adjustment Layer・ベタ塗り・BGM・ED だけ |
| 通常のレビュー動画（ユニクロ・GU・無印・購入品紹介など） | Paste DB の「わむうテンプレ」（マスト / テロップ / 効果音 / エフェクト / 基本のブランドロゴ） |
| ショート（縦型） | 文字起こし字幕 → Klee 28（0, -433）、ズームレイヤー、クリック音、ショート〆 |

必要なプラグイン: MP_テロップパック、MP_レビューパック、KAMAKEN（ズームツール、ページスクロール、フレームテロップ）、SVM Billie Titles、Button 4 - Notification、縦書き、Adjustment Layer（`~/Titles` と `共有用_Titles` の 2 つ）。

> 解析用のスクリプトは `editing/tools/paste_db.py`。DB の生データ（個人的なクリップボード履歴を含む）はリポジトリに入れていない。
