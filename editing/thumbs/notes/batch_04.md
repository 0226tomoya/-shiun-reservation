## 作業で分かったこと（再現のやり方）
- **一番効いたのは「1 文字（または数文字の塊）ずつのレイヤーに分けて fit」**。1 行まとめだと字の大きさの違い（の・が・を が小さい等）や字間のずれで IoU 0.2〜0.4 止まり。分けると 0.5〜0.8 に上がり、点数が 10〜20 点伸びた（ewsv 28→47、Jhdi 23→36、UVCa/pZkT 40→52、vjg 51→60）。
- **最初の size は文字が画面からはみ出さない大きさにする**。はみ出すと fit の外接矩形が画面の端で切れて、大きさを大きく誤る（CFzF・65eh で「って」が画面外へ）。
- **背景が白っぽい（白い壁・白シャツ・白い余白）ときは tol を 8〜12 に下げる**。28〜30 のままだと壁や服まで「元の文字」と見なされ、fit が字を巨大化し、erase で服がにじむ。
- **ロゴ・帯・枠の erase は "full" ではなく色指定（colors）にする**。full だと採点の「元の形」に入らず、描いたロゴ・帯がすべて外れ扱いになる（5MzX は full→色指定で 52→80）。
- **黒い縁取りの文字で、背景に黒い服があるとき**は、縁を外して白だけで fit してから縁を戻す（fit は一番外の縁の色を探すので、黒い服を文字と取り違える）。
- **runs に fill（グラデ）を付けるときは各 run に fill を書く**（レイヤーの fill は runs があると無視される）。グラデ文字に shadow だけを付けると（縁なし）、text-shadow がグラデの上に乗って文字が黒くつぶれる。縁を 1 本付けて影は縁側に回す。
- **NotoSerifJP（5 ウェイトで約 40MB）と ShipporiMinchoB1（約 44MB）を同じ spec で使うとブラウザが落ちる**（TargetClosedError）。混ぜない。

## この担当分で分かった、わむうのサムネの決まり
- **型は大きく3つ**: ①ユニクロ・GU 系「人物＋極太ゴシック白（NotoSansJP 900 相当）＋黒ぼかし影」、②shiun 告知「写真コラージュ＋白い明朝（Shippori/Zen Old 系の太め）＋英字のコレクション名・発売日（細身のセリフ体）＋左上 shiun ロゴ」、③落ち着いた解説「白い細枠（太さ 3〜5px、端から約 20px）＋中央に字間の広い太ゴシック（ZenKakuGothicNew 700、字間 0.2）の2行」。
- **ロゴは左上が定位置**（ユニクロは赤い正方形 2 枚の横並び、英字とカタカナの順はどちらもある）。複数ブランド比較では上段に正方形ロゴを横一列、または紙袋の上に大きく貼る。shiun は左上に小さい小文字ロゴ、右上に「26 Spring 3rd Collection」。
- **文字の大きさは「ひらがなの助詞を小さく」**（の・が・を・に・すぐ・とは? を本文の 6〜8 割）。数字（3、2026）や大事な名詞（名作・買い）は逆に大きくする。
- **色は白が基本、強調は黄 #fce40c か金グラデ**、赤は ◎ やロゴ・矢印などの差し色だけ。帯は黒の半透明（0.5〜0.75）を見出しの下半分に敷く。
- **手書きの添え書き（白＋黒ぼかし）**を、縦書き・少し傾けて画面の端に置く: 「低身長のカリスマが答えます!!」「大人男性必見」「低身長デザイナー」「ユニクロUまじでいい!!」。
- **言葉の傾向**: 「低身長」「買うべき」「これは買い」「今スグ買って」「全て分かる!!」「身長別サイズ徹底比較」「最近買ってよかったもの」、ブランド名の列挙（COMOLI / barbell object / LIDNM / AURALEE / SEVEN BY SEVEN / OUR LEGACY）。英字の筆記体（2026 Spring、flare / straight / wide）を添える。

## 足りない機能（render.py / fit.py への要望）
- runs の size を em（レイヤーの size に対する比）で書けるようにしてほしい。今は px 固定なので fit が size を変えても runs が追従しない（runs のある行は fit がほぼ効かない）。
- レイヤーの fill（グラデ）を runs にも自動で引き継いでほしい。グラデ＋影（縁なし）で文字が黒くなる不具合。
- fit の外接矩形を画面外まで描いて測ってほしい（今は画面の端で切れる）。
- フォントの埋め込みを「使うウェイトだけ」にしてほしい（大きいフォント2つでブラウザが落ちる）。
- fit の「元の文字の色」を、縁取りではなく文字色で探す指定（例 "fit_color"）が欲しい（黒縁×黒い服の誤検出）。
- 採点の「元の形」に、full の erase で消した範囲のうち描いた図形の範囲も入れてほしい（帯・ロゴを full にすると損をする）。
- 立体（ベベル）文字、輪郭だけの巨大英字（ewsv の背景）を描く手段。
