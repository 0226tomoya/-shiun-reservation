## 分かったこと（round7_mid_1）

### 新しく効いたやり方
1. **1 行のまま残っている層を split → 字ごとの書体候補つき tune（明朝の層は明朝候補、ゴシックの層はゴシック候補、英字は候補なし）→ 書体を固定してもう 1 周**。これが一番効いた: ruBH 48→67、WG8h 51→66、qxlX 59→71、R8hP 51→62、Zc7F 47→56、wd5 65→75、yW8R 42→49、k4sF 44→54、8P7b 81→87、KuXi 71→77。5 周目に 1 文字ずつにしてあった枚でも、副題・小見出し・英字の行が 1 行のまま残っていることが多い。
2. **元のサムネの文字に「広い黒いもや」があるときは、再現の文字の影を外す**（影があると erase がもやごと消して背景が明るくなる。影を外すと元のもやが背景に残る）。r6Jx 48.6→56.9、Bm2x 61.3→67.5、Wd_G 43→45、Qtl0 +1.8。全枚に試すのは 2 回の描画で済むので安い（103 枚中 11 枚で上がった）。
3. **斜体の数字・英字は skew を付けて外接矩形合わせ**（Famd の「20」: skew -8 で +4.9。-14 は下がる）。ただし tune.py の SKEWS は 0 か -2 を選ぶことが多く、元が斜体に見えても点は上がらない枚が多かった（9_Mc、_lTN、d7HP、ewsv、3DDx）。
4. **小さい字の行の字が散っているときは、1 行に組み直す → split → 狭い範囲の tune（PAD 12・S0 0.94・S1 1.06）**。点は同じで字がそろう（eqws）。広い範囲の tune だと字が散る。
5. **手書きの小さい行は向き・色・字間を拡大して読み直す**（XDRH: 黒字白縁・右上がり・字間 -0.23 と読んでいたが、実際は白字・右下がり 8.5°・字間 0）。

### split してはいけない層（今回の崩れの原因。splitc.py で外した）
- 回転した層（RUUU の縦に回した「2025」→ 字がばらばら）。
- 価格・日付・記号入りの行（kMPt の ¥1,990 で「1」「,」が縮む、pZkT・UVCa の日付と cm の札が崩れる）。
- 細い欧文の大見出し（hDq4 の CLOSET TOUR が C LOSE T に、wd5 の BEST BUY の T・Y が浮く）。点は +10 でも見た目が崩れるので、列の切れ目から矩形を取り直すか戻す。
- 遠近の付いた金文字（Wd_G は字が重なって ン が シ に見えた）。
- 字間の詰まった斜体の行（AL2T の上の行、8Xti の バレない、5-ign の ロング コート）は split＋tune で字の間が空く。斜体の字は列が重なって画素の切れ目で切れない。

### 効かなかったやり方
- 斜体の候補（SKEWS）を全レイヤーにかける: 0〜-2 を選び ±0.5。
- 消し残り（8nQq の 発売‼ の下端）を erase の矩形で広げる: 見た目は直るが集中線も消えて −1.1。
- 手書きの書体の入れ替え（cr8t の英字＋かな: Yomogi・KleeOne・ZenKurenaido はどれも −2〜−3）。
- 目で見積もった矩形での合わせ（uFDK・3DDx・n5nr は −0.4〜−1.2）。矩形は必ず画素の列（白の列の切れ目）から取る。半分の大きさの比較画像から目で測ると外れる。

### 足りない機能
- **split.py が回転・斜体の行に対応していない**（回転した行は字の位置がずれる。斜体は字の外接矩形が重なる）。斜体の行を「行の形を保ったまま字間だけ詰める」 tune（spacing だけを動かすモード）が欲しい。
- tune.py に「隣の字との間隔を保つ」制約が無い（字ごとに独立に動くので、字の間が空いたり重なったりする）。
- erase の「影・もやは消さない」指定（今は影を描くと erase が影の範囲まで広がる。影を外すか描くかの二択）。
- 集中線のある背景で、文字の範囲だけを消して線を残す erase（線の向きに沿った inpaint）。
- 遠近の付いた金文字（Wd_G）は css_transform で行ごと合わせる道具が要る。

### 自作の補助（scratchpad/r7/）
- at.sh（1 行の層があれば split、無ければ書体候補 tune。明朝／ゴシック／英字で候補を分け、点が +0.1 以上なら残す）、grp.py（層を明朝・ゴシック・その他に分ける）、splitc.py（split してよい層の判定）、nosh.sh（影を外して良ければ残す）、crop.py（元と再現の同じ範囲を並べる）。
