## この担当分で分かった、わむうのサムネの決まり

- **型は大きく 3 つ**。(1) 白枠（3〜5px、外から約 11〜25px 内側）＋中央に字間の広いゴシック 1〜2 行（ZenKakuGothicNew 700〜900、字間 0.1 前後、影はごく弱い）＋左上か上にブランドロゴ。全身コーデの「静かな」回（U4f・7PH6・zMHo・IdOi・OWGJ）。(2) 画面の下半分〜下 1/3 に極太の大見出し 1〜2 行＋黒の大きいぼかし影（ハウツー・購入品・Q&A）。(3) 黒帯や赤・黄・金の強い色の見出しで煽る回（Vv43・iM6y・T1Mb・FTPK・nlUP）。
- **大見出しは「太い明朝」か「太いゴシック」**。明朝は NotoSerifJP 900 が一番近く、元は**長体（横 0.72〜0.8 倍）**のことが多い（u-yF・cIFx・w1dT）。ゴシックは NotoSansJP 900、強調の行は右に少し傾ける（skew -6〜-8）。
- **色の組み合わせ**は ほぼ「白文字＋黒の大きいぼかし影」。差し色は 黄（#ffea01・#ffd801）、赤（#f20002、赤グラデ #f50a00→#9a0000）、金グラデ、紺（#171d29）。1 枚に差し色は 1 色だけ。
- **影は大きくぼかす**。白文字の影は `0 0 18〜24px rgba(0,0,0,.6〜.75)` にすると点数が一番高かった（細い影だと元の影の名残と合わない）。
- **助詞・送り仮名は小さく**（「でも」「に」「の」「こそ」「うべき」「とは?」「以下の」）、名詞や数字を大きく。数字は特に大きい（「20」「165cm」「5.5cm」）。
- **ロゴの位置**: UNIQLO・MUJI・GU・FamilyMart の四角ロゴは左上（約 x10〜40, y10〜40, 一辺 110〜170px）か右上。2 ブランドなら左上と右上に分ける。UNIQLO:C は黒ロゴ＋白いぼかし。ブランド紹介回はロゴを画面の縁にずらっと並べる（nlUP・OWGJ）。
- **手書き風の小さい注記**（「低身長のカリスマが解説!!」「アパレルディレクターが解説」「〇〇が厳選!!」）を見出しの上か右上に、白・少し傾けて・黒いぼかし影で置く。
- **言葉の傾向**: 「低身長」「165cm以下」「164cm」「買うべき」「買ってよかった」「ぶっちゃけ」「最強」「全て分かる/解決」「絶対買い」「?」で問いかけ。
- 文字が人物の後ろに回る（人物を前に出す）作りが多い（fay・nlUP・GjAV の「5.5cm」）。

## 足りない機能（render.py / fit.py へのメモ）

- **runs の size が px 固定**なので、fit が size を変えても runs の大きさが変わらない。runs の size を「親の何倍（em）」で書けるようにしてほしい。今回は大小の混ざる行を 1 かたまり／1 文字ずつ別レイヤーに分けて逃げた。
- **fit の初期値（外接矩形合わせ）が、小さい仮名の混ざる長い行で大きく外れる**（大きくなりすぎて画面からはみ出す）。1 文字ずつ（列の切れ目で）分けて fit する機能があると良い。今回は手元の補助スクリプトで列の切れ目を探して分けた。
- **fill（グラデ）＋ shadow で、影が透明な文字の上に透けて文字が暗くなる**（background-clip:text の仕様）。今回はグラデのレイヤーに細い strokes を付けて影を縁の層へ逃がした。
- **image レイヤーは IoU の相手（元の文字の画素）に入らない**ので、ロゴが大きいと IoU が下がる。今回はロゴの範囲に、その画像の主な色で色指定の erase を重ねて数えさせた。image を自動で数える方が素直。
- **人物の後ろに回る文字**を表せない（前景のマスクが無い）。
- **縁取り（strokes）があると fit の相手の色が一番外の縁の色になる**ので、黒縁の文字は背景の暗い所を拾って fit が崩れる。縁取りの色ではなく文字色で合わせる選択肢がほしい。
- 筆文字・筆ペン系（「漢」、QJfx の見出し、oywM の「今話題の」）、モノスペースの英字、手書きのラベルに近いフォントが無い。
- 炎のテクスチャ（fay）、金の光沢（FTPK）、集中線（T1Mb）、薄い文字の羅列（u-yF の背景）のような質感・模様は表せない。
