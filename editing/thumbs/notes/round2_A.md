# round2_A（round2_low.tsv の先頭 20 行）

fit.py は使わず、自作の軽い補助（スクラッチパッド `r2A/`）で直した:
- `groups.py` / `mins.py`: 文字色の画素の「列ごとの数」から字の切れ目（0 または極小の列）を出す → 1 文字ずつの x 範囲
- `chars.py`: 1 文字 1 レイヤーを作り、`tgt`（元の文字の外接矩形）と `m`（IoU を見る範囲・色・tol）を付ける
- `snap.py`: 描いた文字の外接矩形を `tgt` に合わせ（size・scale_x・x・y）、最後に ±4px ずらして `m` との IoU が最大の位置に置く
- `try.py` / `fontloop.sh`: フォント・太さを差し替えて snap → 採点し、良い方だけ残す
（`tgt`・`m` は render.py が無視する追加キー。点数は `bash run.sh ID` の値）

## 分かったこと（round2 の低い点を直すとき）

1. **一番多い失敗は「どの字がどこにあるか」の取り違え**。前の spec は 1 文字ずつのレイヤーでも x が等間隔の推測で、字が 1 つ隣にずれていた（gvg・I0PT・uMAR・2av）。文字色の画素を列ごとに数え、0 または極小の列を切れ目にする。濁点・半濁点・「ル」「い」「服」など、切れ目が字の中にも出る字があるので、**切れ目の数と字の数を必ず数え合わせる**。目で見た拡大画像の座標は表示の倍率でずれるので、数値で決める。
2. **外接矩形の上端・下端は、帯の境目で切れていないかを見る**。上の行の字、枠、白い壁、Tシャツが帯に入ると、上端が帯の端（282、378 など）にそろってしまう。全部の字の上端が同じ値なら汚れている。行ごとの画素の数で、数 px 以上ある行だけを数える。
3. **erase の tol は白背景なら 12〜16、色をはっきり指定する**。色なしの矩形の erase（5ySY）や tol 26〜30 の白は、シャツや壁を丸ごと消し、inpaint の汚れで点が大きく下がる。文字色のスポイトの値（#eff1f1・#1e1e1e など）がずれていることがあるので、文字の画素の中央値で測り直す（-Jfk は #282828 にして +1.6 点）。
4. **フォントの種類（ゴシックか明朝か、中抜きか）を先に正す**。Wd8 の 1 行目は明朝ではなくゴシック、5PpR の「わむう」は中抜き、hDq4 の英字は長体のディドン（Italiana）。太さの違いは同じ色の縁 2〜3px で足せるが、**IoU は太い方に寄る**（字の形がずれていると、太いほど重なりが増える）。太くしすぎると見た目が崩れるので、縁は 3px 程度で止めて見た目で決める（wBcp で 10px にすると点は上がったが字が塊になった）。
5. 重い明朝の比べ（同じ位置合わせで点数）: 白い極太見出しは ZenOldMincho 900 / KaiseiTokumin 800 / ShipporiMinchoB1 800 が 1〜5 点の差で入れ替わる。決まった勝ちはなく、`fontloop` で 3〜4 種を試すのが早い。細い明朝（67Dt）は ZenOldMincho 400 が最良（Shippori・Hina・NotoSerif より 1〜3 点上）。筆文字風の黒（-Jfk）は ZenAntique。
6. 元の画素の外接矩形に描いた字の外接矩形を合わせ（size と scale_x）、その後 ±4px ずらして IoU が最大の位置を選ぶと、1 文字ずつの IoU は 0.6〜0.9 になる。行全体を 1 レイヤーで合わせたときは 0.2〜0.4。

## 足りない機能・メモ
- 半透明の大きな背景文字（qiV5 の「28」）は、色で消すと後ろの服を拾い、正しい位置に置くと点が下がる。半透明の文字専用の消し方（描いた形で消し、的は元の画素の明るさの差で決める）が欲しい。
- 縁取りの見た目と IoU の向きが逆になることがある（太らせると点が上がる）。縁取りの太さには上限を決めるか、iou_tol も合わせて見る方がよい。
- 他の担当と同じ時間に specs を書いているので、最後の点が自分の変更だけの値かどうか分からない枚がある（gvg）。
