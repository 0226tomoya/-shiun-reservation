# サムネ再現の担当分の進め方（各エージェント共通）

作業場所: /home/user/-shiun-reservation/editing/thumbs （README.md と render.py の先頭の仕様書式を最初に読む）

担当の各サムネ（list2y.tsv の行番号で指定。動画ID は 1 列目）について:
1. 元画像を見る: Read で /tmp/claude-0/-home-user--shiun-reservation/d72f7582-7e9c-5464-8148-e66e3d2158e4/scratchpad/yt/thumbs/ID.jpg
   文字・帯・枠・矢印・ロゴを全部読み取る（文字は 1 文字も間違えない。改行・ルビ・小さい注記・英字の飾り文字も）。
2. specs/ID.json を書く: erase（元の文字・図形の範囲を漏れなく。ロゴや帯は "full":true）、layers（下から順）。
   フォント・太さ・色（スポイトの代わりに python で元画像の画素の色を測ってよい）・縁取り（多重可）・影・グラデーション・傾き・縦書き。
   ロゴは元画像から切り抜いて assets/logos/ に保存し image で置く（既にあるものは使い回す。名前は brand_variant.png）。
3. `bash run.sh ID fit` で自動調整＋採点。比較画像 /tmp/claude-0/-home-user--shiun-reservation/d72f7582-7e9c-5464-8148-e66e3d2158e4/scratchpad/th/out/ID_compare.jpg を Read で見る。
   右上（文字を消した背景）に元の文字が残っていれば erase を広げる／"full":true／"grow"。
   形が合わなければ フォント・太さ・縁取り・字間・行間・runs を直して再実行（fit は位置と大きさだけ詰める。フォントの選択は自分で判断）。
4. 1 枚につき最低 3 回は「直す→採点→見る」を回す。目標: 点数 80 以上、各文字レイヤーの fit_iou 0.85 以上。届かなくても 1 枚 6 分を目安に次へ（理由をメモ）。
5. notes/batch_NN.md（NN は自分の担当番号）に 1 枚 1 行で追記:
   `| 行 | ID | 型（例: 大見出し2行＋ロゴ / 細明朝センター / 人物右＋文字左 …） | フォント | 色・縁取り・効果 | 点数 | IoU | 残った差 |`
   最後に「この担当分で分かった、わむうのサムネの決まり」を箇条書き（レイアウト・文字の大きさ・色の組み合わせ・ロゴの位置・言葉の傾向）。

決まり:
- render.py・fit.py・run.sh・README.md は書き換えない（足りない機能はメモに書く）。他のエージェントの specs は触らない。
- git の操作はしない（コミットはまとめ役がする）。
- 最後の返事は日本語で短く: 枚数、平均点、平均 IoU、分かった決まりのトップ 5、足りない機能。

## 追記（03:00 時点）

  erase の `"by":"layers"`（描いた文字の形で消す。白い服を守る）、`"front"`（人物を文字の手前に戻す）、`"fit_color"`、runs の `size_em`。
