# A24 修正版との差分 02 — テロップ（title 要素すべて）

- こちら: `editing/output/A24_latest.fcpxml`（10/10 書き出し）
- 修正版: 編集者が直した `編集後.fcpxmld/Info.fcpxml`（10/12）
- 方法: 両方の本編のすべての `title` を、つながったクリップ・入れ子の中まで平らにして取り出した。テンプレート名（effect の name）、`text-style` の runs（文字ごとの書式）、全 param（位置・配置・アニメート など）、フィルタ、変形を見ている（scratchpad `telop/extract.py`）。
- 刃で切れただけの同じテロップ（同じ文字・同じ位置で切れ目なく続くもの）は 1 本につないで数えた（`telop/cat.py` の `merge`）。カッコ内は切れ目込みの本数。
- 対応づけ: 説明テロップは「文字の似ている度合い（difflib）＋同じ素材の時刻（親の mc-clip の src から求めた時刻）に乗っているか」で 1 対 1 に組んだ（`telop/align.py`）。src が 50% 以上重なれば文字が全く違っても同じテロップの書き直しとみなした。
- 調整レイヤー（Adjustment Layer。title 要素だが文字なし）は 03 で扱うので除いた。
- 発言との時刻合わせは、こちらの古い書き出し（v23 の mp4）の音を文字起こしし直して測った（6.2）。`cmp/words_src.json` は実際の音と 30〜85 秒ずれているので使っていない（6.2 の注）。

### 6.2 話し始めからの遅れ・話し終わりからの残り

**測り方**: こちらの古い書き出し（`A24_v23_preview.mp4`、同じマルチカム）の音を faster-whisper（medium）で文字起こしし、v23 の本線のクリップで素材の時刻（mc-clip の src）に直した（9298 語、scratchpad `telop/words_asr.json`）。それを両方のタイムラインに当て、説明テロップごとに「その文に一番合う発言のかたまり」（文字の重なり 0.45 以上）を探して、
- 遅れ = 字幕の頭 − そのかたまりの最初の語の頭（+ は話し始めより後に出る）
- 残り = 字幕の終わり − そのかたまりの最後の語の終わり（+ は話し終わった後も残る）
を測った。修正版の文は EC 調で発言と文字が合わないので、対応するこちらの文で見つけた発言の位置を使った。

## 7. 何がダメだったのか

1. **文の材料が「話し言葉の要約」だけだった**。発言を短く言い換えているので、口語の副詞（少しだけ・ほんの少し・若干・超・意外と）、「〜ように」「〜作りました」の語尾、一人称、主観の効果（スッキリと着れる見た目）が残った。修正版は EC の説明文（plan に入っているのに使っていない）を土台に、発言は「どの話題をいつ出すか」にだけ使っている。
2. **字幕を出す発言を選びすぎた**。決めゼリフ・前置き・自分の話・販売実績・サイズのおすすめも字幕にしていた（28 本消された）。1 分あたり 2.14 本は A19（約 1.9〜2.0）より多い。
3. **見出しを機械的に付けすぎた**（55/73 本）。特に Detail を「その他」の受け皿にしていた（15 本）。理由・効果・問題提起の文にも見出しが付いていた。
4. **数値・用語の「正」を持っていなかった**。番手（1/16・2/28）、ゲージ表記（12G）、部位名（アウトソール・コバ・甲）、全長 127cm などは EC・仕様書にあるが、発言の言い方（真ん中部分・上から見た時に）のままだった。逆に、確かめていないサイズのおすすめ（cm）は字幕にしていた。

## 8. 自動で修正版に近づけるルール案

### 8.1 文を作る（`plans/A24_subtitles.json` を作る段）

1. **材料の優先順位**: ① plan の `products[].design / material`（EC の説明文）を「。」で文に切った候補 → ② 台本 → ③ 発言の要約。発言の区間ごとに、①の候補との一致（文字の重なり）が 0.35 以上なら①の文を使う。無ければ③。
2. **1 枚 = 1 つの仕様**。EC の 1 文が 46 文字を超えるときは「、」「ので」「ことで」「あり」の後で 2 枚か 2 行に分ける（2 行は合計 58 文字まで）。色の説明は色名（クレジットの英字大文字）1 語ずつの枚にする。
3. **語尾の書き換え表**（文末だけ。体言止め・「〜に」は残してよい）:

| こちらの語尾 | 修正版の語尾 |
|---|---|
| 〜を使用 | 〜を採用 |
| 〜に作りました／〜作り | 〜に設定／〜に設計しました |
| 〜が出ないように／〜すぎないように | 〜を抑えています |
| 〜なデザイン | 〜な仕様に |
| 〜に仕上げました | 〜に仕上げています |
| 〜着られる／着れる | 〜着用していただけます（ED・季節の話のときだけ） |

4. **消す文の条件**（字幕にしない）:
   - 一人称（僕・私）・自分の身長体重を含む文
   - 「超」「マジで」「意外と」「何も気にしなくても」など口語の強調を含む文
   - 販売実績（〜分で完売・〜足以上を販売）は商品紹介の最初の 1 本だけ。2 本目以降は消す
   - サイズのおすすめ・cm の目安（「〜の方は〜がおすすめ」「ウエスト〜cm の方まで」「着丈〜cm」）。サイズ表が出る商品は特に出さない
   - 顔出しの決めゼリフ（plan の `face: true`）。OP・ED では出さない
   - 直前 30 秒以内の字幕と一致 0.5 以上の文（同じことの言い直し）
5. **句読点**: 「。」は使わない（文の途中の「。」は「、」か「で」か改行に）。読点は 1 行に 1 つまで。

### 8.2 見出し

- 見出しを付けるのは「部位・素材・仕様の名詞」で始まる文だけ（例: ヒール・アッパー・身幅・襟・糸・バックル）。理由（〜ため・〜ので）、問題提起（一般的な〜は）、効果（〜につながる・〜印象に）で終わる文には付けない → lane 3 の「見出しなし」にする。
- 見出しの選び方: 素材・糸・生地 → Material、色・色味 → Color、元ネタ・ボタンの数・バックルの作り → Design、丈・幅・シルエット → Silhouette、小さな部品（ゴム・コバ・ヒール）→ Detail。**Detail を既定値にしない**。
- 見出し付きは説明全体の 6〜7 割（修正版 35/54）。

### 8.3 長さ・切り方

- 長さの目安（修正版の分布）: 20 文字以下 → 3〜6 秒（中央 4.7）、21〜35 文字 → 7〜11 秒（中央 9.4）、36 文字以上・2 行 → 9〜14 秒（中央 11）。上限 16 秒（こちらは 20.5 秒があった）。見出しなしの補足（lane 3）は 1 枚あたり 3 秒ほど長め。
- 頭と終わりは本線の切れ目（今どおり）。頭は「その話の最初の語」の −1.0〜+3.0 秒にある切れ目を選び、2.5 秒以上前の切れ目しか無ければ後ろの切れ目を使う（修正版は先に出すぎた 11 本のうち 8 本をこの範囲へ動かした）。終わりは話し終わり +0.5〜+3 秒の切れ目。数値だけの短い文・2 枚に分けた前半は話の途中で切ってよい。
- 横に並ぶクレジット（一覧の 4 足など）があるときは、説明テロップも同じ数に分けて頭と終わりをそろえ、1 枚 2.3〜2.5 秒にならす。

### 8.4 2 行

- 2 行の位置は 1, −440.734（今のルール）を**必ず**適用（こちらでは改行入りの 1 本が 1 行の位置のままだった。原因は未確認。改行を含む文は最後に位置を 2 行用に直す処理を通す）。
- 改行の位置は「〜ことで／〜ので／〜あり／〜ため／〜いく」の直後を優先。

### 8.5 追加素材の型

- 試着会: plan に試着会の素材があれば、その商品の価格のあと・次の商品の前に入れ、感想をタイプライター（4.1 の値）で起こす。1 枚 19 文字前後・最大 35 文字・改行なし。補う語は半角カッコ。最後の 1 枚を 45 にする。前振りの説明テロップ「試着会にご来場いただいた方々から実際に履いた感想や着用感を伺いました」を lane 3 で 15 秒。
- 着用サイズラベル: わむうが 1 人で着る場面（plan の着用サイズ。A24 は S、Vネックの 2 人目は 158cm 55kg / XS）に「164cm 58kg」（左）＋「size S」（右、右揃え、(859.9, 405.3)）を 5〜8 秒。
- 旧色・旧作の話をしている間は、旧色のクレジットを左下 (-864, -450) に出す。
- スナップ写真の場所: 写真が無ければ座布団（4.2）を置き、書き出し前チェックで 0 本にする。

### 8.6 チェック（`audit_telop_text.py` に足す）

- 「(追加予定)」「後ほど」「仮」を含む title → エラー
- 説明テロップの「。」・「僕」・「超」・「マジ」→ 警告
- 文頭・文末・読点の後の余分な空白（半角・全角）→ 警告（修正版にも 3 件ある）
- 改行を含む説明テロップの位置が −483.734 → エラー
- 「少シャープ」のような脱字は自動では拾えないので、EC の文から作った字幕は EC の文と 1 文字ずつ照合（一致 0.9 以上なのに完全一致しないものを警告）
