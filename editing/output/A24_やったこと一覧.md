## 2. 10/08 の指示と対応（v14〜v23）
- **クオリティ最優先**。1 フレームのずれ・話の途中で切れるインサート → 全要素をフレームの格子に、インサートの頭・終わり・切り替わりを本線の編集点に（チェック 962 件 → 0 件）

- **LOOK 素材**: 動画は冒頭だけ、写真は冒頭と ED の背景。写真 933 枚を目視で台帳化
- **インサート**: 説明に一番合う場面を。喋り・ガム・ポケット・服や髪を直す動き・スタッフの映り込みは NG → 動きの自動判定＋目視の台帳、字幕の言葉から部位を出して素材を選ぶ
- **ED の画像**: 服は切り抜き、ローファーは掲載用スナップ、ベルトは SNS 用
- **テロップ**: フルテロップにしない（説明と重要な発言だけ）。コレクション名は「26FW Winter 1st Collection」の形
- **素材**: ローファーの写真 16 枚に限定、A24 の完パケへ参照を切り替え、カウントダウン（7.mp4）は切らずにまるごと
- **身長別比較**: A19・A23 のブロックを丸ごとコピーし、サイズ表（検品書の指示寸法）・動画だけ A24 に。身長・体重は A19 から。枠の端に頭頂〜つま先を合わせる
- **青柳さんの顔ぼかし**: 首から上 → 楕円・減衰のマスク＋弱めのガウス（顔は見えない・襟元は見える）
- **テロップの値を全項目で過去データと照合**（Masqualero・縦 140%・文字間隔・行間）→ 400 本すべて一致
- **流用部品の中の A19 の文字・写真**（コレクション名・発売日・LOOK 写真）を A24 に差し替え、チェックを追加
- **確認**: 全編の確認動画（6 分割）、編集記録の送付、スマホの確認ページ（時刻つきの修正依頼フォーム）
- **10/08 夕方の厳しい指摘**（3 分で修正 30 個、いらないインサート、調整レイヤーの細切れ、FCP で読み込めない）→ 原因はテロップのフェードが A19 の ID のままだったこと。参照チェックを追加し、修正 1〜30 を受けて作り直し

4. 説明テロップが話し言葉の要約だった（修正版は EC の説明文寄り、28 本削除）
