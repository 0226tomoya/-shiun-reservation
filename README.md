# 資産運用アシストエージェント — Serenity シグナル × 新NISA

X の Serenity (@aleabitoreddit、通称「白毛股神」) の公開株予想投稿を分析し、
新NISA (つみたて投資枠 / 成長投資枠) とその他投資信託の売買判断をサポートする
React 製シングルページアプリです。

## 機能

- **Serenity シグナル一覧** — 公開トラッカー・報道から再構成した銘柄言及アーカイブ
  (日付 / ティッカー / テーマ / 確信度 / テーゼ / 言及後パフォーマンス / 出典)。検索対応。
- **テーマ・ヒートスコア** — 確信度 × 鮮度 (6ヶ月半減期) で直近の言及集中テーマを可視化。
- **NISA 枠管理** — つみたて枠 (年120万)・成長枠 (年240万)・生涯限度額 (1,800万 / 成長枠1,200万) の消化メーター。
- **買い提案エージェント** — リスク許容度に応じてコア (インデックス積立) / テーマ・サテライト (投信・ETF) /
  個別株サテライトへ月予算を配分し、NISA 残枠と残月数から月額を算出。
- **売却・見直しアラート** — 保有銘柄に対し、急騰後の段階利確・含み損の見直し
  (NISA は損益通算不可)・集中度超過・枠復活タイミングをルールベースで診断。
- データはすべてブラウザの localStorage にのみ保存されます。

## 開発

```bash
npm install
npm run dev    # 開発サーバー
npm run build  # 本番ビルド
```

## データ更新について

X 本体は認証なしで読み取れないため、`src/data/serenitySignals.js` に公開情報から
再構成したシグナルのスナップショットを同梱しています。ライブ化する場合は
X API v2 (`GET /2/users/:id/tweets`、Bearer Token 必須) で @aleabitoreddit の
タイムラインを取得するバックエンドを用意し、同ファイルの形式に変換してください。
