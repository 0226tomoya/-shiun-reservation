# 価格・商品名の照合

- 実例: 身長別インサートの ¥6,930（正 ¥15,400）、ユニクロ 2 品の価格の入れ違い、BB Cream の画像に「O GREASE ¥3,080」、ミュールに「GRAIN CHELSEA BOOTS ¥16,500」、無印 Item 8 の商品名と価格の取り違え。
- 原因はほぼ「前のテロップをコピーして直し忘れ」。流用したら 1 点ずつ照合。
- 正とするもの: shiun＝企画の台本（2026-09-16〜白石さん）と EC、他社＝公式の商品ページ、展示会＝先方の資料の表。
- Color 欄は展開色を全部。特殊な文字（RETØUCH の Ø）もそのまま。
