# フィボナッチ構図（A25 サムネ v4 で作った手順）

## 道具
- `python3 editing/thumbs/golden_overlay.py IN.png OUT.png 向き` … 黄金比の線（0.382・0.618）と黄金螺旋を重ねる。螺旋の目（収束点）の座標を表示する。
  - 向き: 0 = 目が右下 / 1 = 左下 / 2 = 右上 / 3 = 左上。螺旋は枠に合わせて伸ばしてある（Photoshop の切り抜きツールの「黄金螺旋」と同じ）。
  - 1280×720 では、向き 0 の目が (929, 522)、向き 1 の目が (351, 522)。
- 同じ関数 `spiral(W, H, 向き)` を、組むスクリプトから import して使う（`a25_psd.py` の `EYE`）。

## 手順
1. **まず今の案に重ねて測る。** 主役がすでに目の近くにあることも多い（A25 は靴が最初から目の近くにあった）。大きく動かす前に、ずれを数字で見る。
2. **螺旋の向きを決める。** 主役（商品）がある側に目を置く。大きな弧が「タイトル → 縦の文字 → 下の商品名 → 主役」を通る向きがよい。視線の順番になる。
3. **主役の「一番の特徴」を目に置く。** 物の中心ではなく特徴の点に合わせる（A25 は U チップの縫い目の先）。
   - 商品の画像の中でその点の座標（`SHOE_PT`）を測る。
   - 置く位置は `sx = 目x − 点x × 倍率`、`sy = 目y − 点y × 倍率` で決める。
   - 主役の端（かかと・つま先）が 0.236 か 0.382 の線に揃うと、さらに締まる。
4. **線に揃える。** 横の線は高さ × 0.146 / 0.236 / 0.382 / 0.618 / 0.854、縦の線は幅 × 0.236 / 0.382 / 0.618 / 0.764。
   - 小さい英字の段（季節・MEN'S STYLE）は 0.236 の線に置く。
   - 縦書きは 0.382 の線から始めて、0.854 の線までに収める。
5. **余白・間隔はフィボナッチ数にする（8・13・21・34・55・89）。**
   - 左右の余白は 55。ロゴ・季節・商品名・縦書きの端を全部これで揃える。
   - タイトルからサブタイトルまでは 34。
   - 罫線の長さは 89、罫線と文字の間は 21。
   - 縦書きの字の大きさは 21、列の間は 34。
6. **詰まりを解く。** タイトルの上が詰まっているときは、0.9 倍にして上の余白を 34 にする。文字レイヤーのまま縮める方法は `shiun-thumb-psd-export` を見る。
7. **確かめる。** 重ねた画像（`*_黄金螺旋.png`）も一緒に渡し、どこを何に揃えたかを数字で伝える。

## 気をつけること
- 線に揃えるために、読みやすさ（タイトルの大きさ）や商品の大きさを大きく削らない。0.9 倍くらいまでにする。
- 揃えると字の送りが詰まることがある。字間が字の大きさの 1/4 未満になるなら、字を小さくする（24 → 21）か列を分ける（`shiun-thumb-vertical-copy`）。
