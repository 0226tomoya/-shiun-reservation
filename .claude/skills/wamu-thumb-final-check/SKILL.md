# サムネの確認

- 顔・商品を文字で隠していない（パンツの回は文字を上半身に）。
- 「低身長」と身長の数字が入っている。差し色は 1 色。
- かなが小さく、数字が大きい。見出しが画面幅いっぱい。
- ロゴの位置・ブランドが正しい（UNIQLO の 2 枚組の順、U・:C の黒）。
- わむうの写真が盛れている（自撮りの切り出しは使わない）。ゲストの態度が悪く見える画は使わない。
- 誤字・ローマ字の打ち残し（`audit_telop_text.py` と同じ考え方で目視）。
- スマホの小さい表示でも読めるか（縮小して確認）。
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
