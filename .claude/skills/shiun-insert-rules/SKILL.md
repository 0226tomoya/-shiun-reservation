# インサートの決まり

- 置く場所: インサートのかたまりの頭と終わりは本編の編集点。トークだけの所に自動で埋めない（ユーザー指摘で fill_talk を止めた）。
- 素材の選び方: 必ず目で見る（コマを 4 枚以上並べる）。喋っている・髪を直す・ポケット・スタッフ・場面の切り替わりは使わない。
  EC 動画は 1 本の中で場面が変わるものがある（例 6463 は V ネックから始まる）。使う区間だけを確かめる。
- 手ブレ補正: EC・LOOK の動画はすべて A19 と同じ形（`clip` > `video` > `adjust-stabilization type="automatic"`）。
- スロー: LOOK 動画は 50〜75%。`timeMap` の 2 点（time = 素材の頭 + (素材の時刻 − 素材の頭) / 速度、interp smooth2）。
- 2 分割（修正 7）: 左の画像を上のレイヤーにして、画面の中央でクロップ。位置 ±44.4444・半分の幅に合う拡大。
- 全画面のインサートは 1920x1080 を端まで覆う（`audit_inserts.py` で 0 件）。身長別比較の窓と ED の切り抜きは型どおりなので対象外。
- EC 寄り動画の上には A19 の EC 用調整レイヤー（拡大 1.15・位置 3 3・カラー調整）を重ねる。LOOK 動画・写真には重ねない。
- 過去の商品の話: 公式サイト（shiun-store.com/products/detail.php?product_id=…）の商品画像の部分を 750x900 で撮り、位置 -47.3148 0、
  左下に product_label_bottom（商品名 / Color : 色 | Size : …）。A19 21:25 の型。
