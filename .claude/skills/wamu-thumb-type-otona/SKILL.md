# 大人型（白枠＋センター）

- 白い細枠: rect `{"x":12,"y":12,"w":1256,"h":696,"fill":"transparent","border":[5,"#ffffff"]}`（太さ 2〜5px、端から 12〜25px）。
- 画面中央（y≒300〜400）に白ゴシック 1 行: ZenKakuGothicNew 700（または NotoSansJP 700）、size 50〜60、**字間 0.10〜0.30em**、影はごく弱く `0 0 8px rgba(0,0,0,.35)`。
- 2 行目はサブ: 小さく、「-8000円以内で完成するコスパ最高の大人スタイル-」のように **- … -** や **~ … ~** で挟む。
- ロゴは文字の上下に中央揃え（UNIQLO の赤 2 枚組、UNIQLO:C は黒）か左上・右上。
- 縁取り・グラデ・手書き注記は使わない。
- 例: U4fBhdI7t0I（83 点。「まるでドメブラ、ユニクロCの新作シャツ」ZenKakuGothicNew 700・55.9px・字間 0.124）/ HVmj2KwLjxM / 5MzX7s3bgT8 / 6F7yK5ZDFA0
