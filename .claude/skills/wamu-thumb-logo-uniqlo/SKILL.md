# UNIQLO 系のロゴ

- UNIQLO: 「ユニクロ（カタカナ）＋UNIQLO（英字）」の**赤い正方形 2 枚組**（順番はどちらもある）。
- UNIQLO U: 黒の UNIQLO＋U、UNIQLO:C: 黒の UNIQLO＋「:C」（白いぼかし付き）。
- U・C の回は「ユニクロ・UNIQLO 赤＋UNIQLO 黒＋U または :C」の組で並べる。
- 141 本で使用。素材: assets/logos/uniqlo_*（赤・黒・2 枚組・縦 2 段）。
