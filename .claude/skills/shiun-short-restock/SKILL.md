# 再販告知ショート

- 前半は新作紹介型（shiun-short-new-item）そのまま。後半に「完売 → 再販 → 受注期間カード → 価格」を付ける（04 月のサンダル・タンクトップ）。
- 最後は価格カードか本人の締めで終わる。発売日カードは無い。
- 受注期間は Slack の告知（例: 受注期間 10/25 22:00〜11/3 23:59、お届け時期）と照合する。

出典: `editing/knowledge/shiun_ショートの決まり.md`（2026-01・05・08 月の販促ショートの編集データと完成動画 13 本の分析、10/13）。
