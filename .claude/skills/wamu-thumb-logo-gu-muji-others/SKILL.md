# GU・MUJI・ほか

- GU: 青の正方形（黄の文字）、黒い影つきの版あり。中央か右に大きく置く回もある（67 本）。
- MUJI: 臙脂の正方形（35 本）。MUJI Labo は文字のロゴ。
- コラボ（JW ANDERSON・UNDERCOVER）は左上にコラボ、右に親ブランド。
- ブランド名だけの回（AURALEE・COMOLI・LIDNM）は小さい英字ロゴか「COMOLI / blurhms / AURALEE」のスラッシュ区切り。
- shiun の新作と似た他社（プチプラ）商品の画像は出さない（Slack・げんじ）。
