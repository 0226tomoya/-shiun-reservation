# ツッコミ

- ツッコミのテロップ多めが高評価（「ツッコミ多めでめちゃ良かった」「細かいところまでツッコミ編集」）。
- 出演者のボケは流さず、ツッコミ・BGM を止める・寄りのズームなどを必ず入れる（何もないと「痛い人」に見える。A23 28:24）。
- ネタの演出（領域展開など）は好評。テロップのフェードはテロップごとにかける・かけないを選ぶ。
