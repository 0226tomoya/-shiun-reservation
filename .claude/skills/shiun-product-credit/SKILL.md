# 商品の情報（詳細は `editing/knowledge/編集ルール集_わむうsns_1年分.md` の 2 章）

- **正とするもの**: shiun は企画の台本（2026-09-16〜白石さん。それ以前は伊藤さん）と EC。サイズ表は中森さんの検寸データ。他ブランドは公式の商品ページ、展示会は先方の資料の表。
- **コピーして使い回したテロップを必ず照合**（価格 ¥6,930→正 ¥15,400、ユニクロ 2 品の価格の入れ違い、ミュールにブーツのテロップ、コーデ詳細が別コーデのまま、LOOK のカラー「BEIGE」）。
- 書式:
  - コーデ詳細 `カテゴリ / ブランド / 商品名 / ¥価格 | Color : 09 BLACK | Size : WOMEN XL`
  - LOOKBOOK `番号 / カテゴリ / ブランド / 商品名 / ¥価格 | Color | Size / ※8/29(土) 22:00~ 発売`（完売 ※Sold out、未発売 ※Coming soon、他社は購入リンク）
  - ラインナップの商品名ラベル `商品名 / Color : 全色 | Size : XS, S, M`（Color は展開色を全部）
- サイズ表: EC と同じ数値、小数点以下も丸めない、「着丈(ネックポイントから)」、前後差は前・後ろ（・脇）を全部。
- 用語: 身頃（見頃×）、釦ホール、ラウンドトゥ、経緯、貝調、20/2（番手）、コットンナイロン（C/N の読み）、スラブ糸（し）、子ども、試着会、洗濯（選択×）。台本の誤字も疑う。
- 素材・仕様の説明は**その場面で話している内容**に合わせる（別の商品の Material 説明を流用しない）。仕様と違う発言は音声を差し替え（AI 音声で可）。
- 言い間違い（曜日・日付・価格）はテロップで訂正。SALE は「元価格 → ○% OFF → SALE 価格（赤）」。
- 発売は 22:00、ラインナップ動画の公開は 19 時（EC と合わせる）。
