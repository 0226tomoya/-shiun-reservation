# 音なしで分かるショート

- 話す人ごとにテロップの位置か色を変える（わむう・後輩・友人）。
- 画面外の声は漫画の吹き出しのテロップを声の側に。紹介ラベルは縦書きの小さい白文字を人物の横。
- 相手役は背中・肩（横顔まで）が見えるクロップ。光学迷彩のような凝ったモザイクより、ズームで画面から外す（端にぎりぎり入る程度）。
- 商品の話は空いた所に商品画像と詳細。
