# わむうの画角

- わむうの映像だけ上下の余白を付けない・引きすぎない。モデルと並べるとスタイルが悪く見える。人物はモデルと同じくらい大きく。
- 背景は自然光の「家っぽい」部屋（アート・植物・椅子）。物を置きすぎない。げんじチャンネルと同じに見えないようにわむうらしさを出す。
- スタイル補正はわむうに好評なので続ける。
