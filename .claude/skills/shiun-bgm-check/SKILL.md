# BGM

- 付け忘れ 6 回（A10 初稿は公開が 1 週間延びた、3rd Spring、2026-04-13、06-01、06-18）。喋っていない所（インサート・LOOK・サイズ表）で無いと特に目立つ。
- 確認用でわざと入れていないときは、投稿で先に書く。
- 音量は「声優先で音楽小さめ」（わむう）。選曲はよくほめられる。わむうが曲を指定することもある。
- シュールなショートは BGM も効果音も入れない。
出典: `editing/knowledge/編集ルール集_わむうsns_1年分.md`（原文は `editing/knowledge/slack_wamu_sns/`）。

## A24 修正版から（10/12）
- カウントダウン明けは、曲の位置を「タイムラインの時刻＝曲の時刻」にそろえる（止めずに流れていた位置から再開。start = 再開する時刻）。fadeIn は 0.25〜0.3 秒。
- 最後の fadeOut は 3.5〜4 秒（こちらの版は 1.4 秒だった）。
- **+8dB に上げるのは、エンディングカード（声の無い 8.5 秒）の頭から 2.3 秒かけて上げる所だけ**。ED のトークにはかけない（こちらの版は 2003〜2017 秒のトーク中に上げて声とぶつかった）。
- BGM の音量 −17dB は今のまま。
- 本線の声が 6dB 以上小さい所は +3dB を候補にする（修正版で 134 秒に 1 か所。理由は要確認）。
