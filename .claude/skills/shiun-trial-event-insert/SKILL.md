# 試着会の感想などの追加素材

## A24 の修正版の作り（10/12）
- **長さは 1 人 25〜35 秒 × 人数**（A24 は 4 人で 132 秒）。旧ルールの「20〜30 秒」は 1 人あたり。
- **入れる場所**: その商品の価格と締め（「この機会に検討していただけると幸いです」）の後、次の商品紹介の前。予告の発言（A24 は 6:51〜7:05）は残し、字幕をその予告にちょうど重ねる。順番は アイキャッチ（1.5 秒、ふだんは 1.92 秒）→ 試着会 → アイキャッチ。
- **並べ方**: 人を試着サイズの順（37→43）に並べる。
- **映像**: 本線を試着会のマルチカム（映像のアングル＋ピンマイクのアングル、75 カット）に差し替える。縦の動画は 90° 回して 1.78 倍。
- **音**: 各カットに Limiter（Gain +4dB / Output −2dB）と 1ms の音量フェード。
- **テロップ**:
  - 感想はタイプライター（下中央、KleeOne 35）。A24 は 25 本。
  - 着用サイズのラベル（「NN サイズ着用 / cm / 普段履いている靴」、YuMincho 45/30）は右上。A25 の試着会のラベルの複合（ref-clip「試着会 クリップ N」）を流用してよい（中身が同じなら他の回の流用は可）。人の終わりにフェードアウト。
  - 本線の価格つきの商品クレジットは、試着会の間も左上に出しておく。
  - 調整レイヤーは効果なしを 11 本。
- **予告の発言**: 本編で「この後に短いバージョンで差し込んでおきます」と言っていたら、素材を探す（A24 は A27 の素材フォルダにあった）。素材が無ければその発言を切る（A23 で切った）。

出典: `editing/knowledge/A24_修正版との差分/01_カット.md`・`03_インサート・音・構造.md`、`editing/knowledge/編集ルール集_わむうsns_1年分.md`（2026-08 ローファー、わむう）。

## 差し込む素材が無いとき（10/13 ユーザー回答）
- 一般的な決まり: **差し込む素材が無いときは、その予告の発言も切る。** A24 は試着会を入れないことになった。
- plan.trial_event が null なら、`apply_cuts.py --words` が「差し込んでおきます」を含む文（文の頭〜「ご覧ください」）と、続けて同じ話をする文（別動画・長いバージョン・感想）を自動で切る（A24 は 16.2 秒）。

## 別の回の完成 XML から差し込む（10/26、`editing/tools/insert_trial_event.py`）
- 試着会の動画を別の回（A24 なら A27）で完成させているときは、その完成 XML を FCP で書き出してもらい、plan.trial_event に書く: `{"fcpxml": "../sources/A27_試着会.fcpxml", "product": "1.ローファー", "seconds_per_person": 33}`。build_all.sh が apply_overrides の後に差し込む。
- A24 の最終版の試着会 132 秒は、A27 の完成編集のカットを 131.7 秒分そのまま（音のフェード・90° 回転・色まで同じ）並べ替えたもの。字幕（タイプライター）とサイズラベル（試着会 クリップ N）も A27 のまま。
- 人の選び方: アイキャッチで人を分け、右上のラベル（「NN サイズ着用」）でサイズを読む。1 サイズ 1 人（同じサイズなら感想の字幕が多い人）を小さい順に。A24 は 37・39・41・43 の 4 人で、最終版と同じ人が選ばれた。
- 1 人の範囲: ラベルが出る 2 秒前に近いカットの頭から、25〜35 秒に収まる字幕の終わりのうち目安にいちばん近い所まで。編集者は人ごとに 20〜57 秒と幅があり、途中の感想を飛ばすこともある（決まりにはできない）。
- 持ち込まないもの: 元の回の BGM・効果音、どの人にも出ている動画のタイトルの複合、作業用のマーカー（未完了の ToDo を含む）。
- 前後のアイキャッチは 90 コマ（1.5 秒）。価格つきの商品クレジット（左上の product_label）を試着会の間も出す。
- 文字起こし（transcript_cut）はずらさない（audit_inserts がマルチカムの素材の時刻で写すので、ずらすと二重になる）。
