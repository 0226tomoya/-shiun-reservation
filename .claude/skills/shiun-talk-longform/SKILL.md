# 長編（詳細は `editing/knowledge/編集ルール集_わむうsns_1年分.md` の 4・6 章）

- 一番の評価軸は「見やすい・分かりやすい」。フルテロップが標準。
- **ツッコミのテロップ多め**。ボケは流さず、ツッコミ・BGM を止める・寄りのズームを入れる。
- **アバン**は動画で一番伝えたいこと／いちばん共感される発言から（対談は最後の発言を頭へ）。知らない人には肩書きテロップ。態度が悪く見えるカットから始めない。わむうが指定したフックのセリフから入る。
- **インサート多め**（使い回し OK）。撮った着用インサートは全部使う（外の全身着用を「入れまくる」）。話が画で見えるように（脚長→全身、ディテール→寄り、股上・股下→パンツの図、サイズの話→サイズ表、数値の話を顔アップで流さない）。素材がなければ AI 生成画像。
- 商品と関係ない雑談・相手のイメージを下げる話は切る。コラボは相手にも確認。shiun の新作と似たプチプラ商品の画像は出さない。
- テロップで紹介中の商品を隠さない（パンツ→テロップは上半身へ）。
- 街頭インタビューの型: 「Question.N」＋白枠、感想は白縁太字＋✨、商品は画像＋手書き風注釈。
- スタイリング解説は 1.2 倍速。時事は当日公開を優先。
