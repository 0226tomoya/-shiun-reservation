# 伏せ字

- 「〇〇着るな」「〇〇買うな!!」「●●着てたら時代遅れ!?」「〇〇が好き♡」のように、肝心の語を伏せて気を引く。
- 「●●」は黒丸か赤丸、上に「＼ランキング／」「＼買った／」の囲み。
- 例: -gTiqKRoiNc / FDHgAYDAMa8 / nN0bxTWf9IE
