# 〇選・BEST 型

- 数字は**和文より大きく、欧文の極太**（Montserrat 900 / Anton / ArchivoBlack、斜体が多い）か**ディドン体のセリフ**（BodoniModa・PlayfairDisplay 900）。
- 「選」は小さく添える（0.6〜0.7 倍、下寄せ）。
- まとめ回は金の縦グラデ＋茶黒縁＋立体影、背景に集中線（`wamu-thumb-color-gold-gradient`）。
- 「＼ランキング／」のような囲みの小見出しを上に。
- 例: Df9CmIZ8EFA（85 点）/ HcoTwn1KXDY / d57LRGuyX2Q / 5MzX7s3bgT8
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
