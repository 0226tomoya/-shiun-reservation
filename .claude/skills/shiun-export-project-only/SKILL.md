# 書き出しはプロジェクトだけ

- A24 のこちらの版は、イベントの中身（ブラウザのクリップ 1156、asset-clip 133、キーワードコレクション 16）まで書き出していた。asset 1356 のうち 1191 は使われておらず、読み込むと編集者のライブラリが散らかる。修正版はプロジェクトだけで、asset 224 はすべて使われている。
- **使われていない asset を 0 にする**（validate に足す）。
- 素材のパスが `/var/folders/`・`/tmp/`・`~/Downloads/` にあれば警告する（オフラインになる）。修正版にも一時フォルダの画像が 3 枚あった → 次の版で回のフォルダに移して登録し直す。
- 型から来たマーカー（「マーカー 4/10/15…」）はコピーするときに消す。編集者に残す TODO は、名前を「あれば〜」「追加予定〜」にしたマーカーだけ。チャプターマーカー（ピン）は商品の頭と ED に打つ（shiun-timestamps）。
- フォーマットは 1920x1080・59.94p・Rec.709（r340 と r1 は ID の振り方が違うだけ）。

出典: `editing/knowledge/A24_修正版との差分/`（A24 の自動版と編集者の修正版 10/12 の比較）。
