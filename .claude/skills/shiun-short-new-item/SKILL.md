# 新作紹介ショートの作り方（08 月の型＝修正なしで通った最新の型）

1. **形式**: 1080×1920・59.94p・48kHz。本線は縦の撮り下ろし（映像とピンマイクのマルチカム）。
2. **長さ**: 1 品 76 秒（69〜112）、2 品 88〜124 秒。
3. **並べ方**: つかみの結論 1 文（0 秒から、3.7 秒以内）→ 悩み（11〜24 秒）→ 宣言「〜を作りました」→ 商品名カード → 特徴 3〜5 個 → 身長別（164cm S・158cm XS は必ず、4 人の早送り 1 回）→ サイズ表（4.4〜5.1 秒）→ 価格カード → 発売日カード。前置きは入れない。
4. **カット**: ジェットカットで 1 カット 0.65 秒（1 分あたり 77 カット）。
5. **字幕**: 全部の発言に付ける。1 行 11 字（最大 18）・1.6 秒・すき間 0。編集点と同じ時刻に始める（shiun-short-subtitle）。
6. **商品名カード（2026-10-13 ユーザーの手本＝カーコート冒頭）**: **商品名を言うカットの頭**に 3 つを同時に置く。
   - 効果音「決定ボタンを押す32」lane −1・0.617 秒・短いフェード。
   - 商品画像 lane 2: SNS 用高画質の 00001・scale 1.5（5:6 の写真で縦いっぱい）・position `0.572917 0`・カラー調整（ユーザーの filter-video をそのまま）。
   - 商品名テロップ lane 3: 基本タイトル・Masqualero 45（2 行とも 45 の 1 書式）・位置 `-2.04 2.97505`・調整 `1 1.4`・行間 −3・scale 0.7。
   - 長さはカーコートで 1.2 秒（＝商品名の文の終わり）。その間は字幕なし。
   - 調整レイヤーは lane 1 に頭から終わりまで 1 本・scale 1.15・position `0 7.34375`。
7. **身長ラベル**: 左上 `-266.583 357.396`。`164cm / Size : S`。
8. **インサート**: 話している部位を画面の 50〜80% に入れる。インサートの音は消す。
9. **終わり**: 価格カード `¥ 6,600 - tax in`（位置 `-2.04 43.0501`）→ 発売日カード `2026.10.31 sat 10pm - Release`（4.55 秒）。文言・位置は長編と同じで、scale だけ 0.6。商品名・価格・発売日は台本と EC で照合する（shiun-price-name-check）。
10. **音**: BGM は Epidemic Sound のインスト 1 曲を頭から最後まで −28〜−23dB。効果音は商品名・価格の頭と、数え上げのクリック（+12dB）だけ。
11. **チェック**: 文字化け・画像バグ・最初の 1 秒に結論があるか・音なしで話が分かるか（shiun-export-check）。書き出しは高画質ファイルを Dropbox で渡す。

## ユーザーがカットを直した XML に入れ直すとき
- `editing/tools/short_overlay.py BASE.fcpxml overlay_*.json --out …`（指示は `editing/shorts/26w1st/overlay_*.json`、時刻はカットの番号で書く）。本線（mc-clip）は文字列のまま触らない。
- `editing/tools/short_cut_compare.py BASE OUT` で本線が 1 コマも変わっていないか、`short_overlay_preview.py` で静止画を見る。
- インサートは SNS 用高画質（ローファーは色調整済みの縦写真）。ユーザーの XML の resources にある asset を ref で使う。文の切れ目から切れ目まで 1 文 1 枚。SNS のモデルはわむうではないので、身長ラベルは本人の画の上だけ。

## 渡す前
- `python3 editing/tools/validate_fcpxml.py` が OK になるまで渡さない（XML として読めるだけでは FCP で読み込めないことがある）。

## ショートのカットの詰め方（10/13 ユーザーの直しから）
- 0.12 秒を超える間は残さない。端は声にぴったり（頭は子音の高い音まで含めた出だしの 0.005 秒前、尾は声の終わりの 0.01 秒内側）。余白を広げて「切れ」を防ぐのは誤り。
- 長さは 1 品 70〜80 秒・2 品 85 秒前後。確かめは editing/tools/cut_check.py（詰め足りない・0.12 秒超の間を 0 に近づける）。詳しくは editing/knowledge/shiun_ショートの決まり.md。
