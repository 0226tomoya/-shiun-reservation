# Tier 表型

- ランク文字（S/A/B…）を金〜オレンジのグラデ（黄→クリーム→オレンジ）で、枠とラベルの表を背景に。
- 見出し「最強Tier表」「低身長に一番似合うのはどれ？」を金グラデの斜体＋茶黒の細縁、背景に集中線。
- 表の枠・ラベルは写真のまま残すことが多い（再現が難しい）。
- 例: yXbm2bU0Tis / 9CnZsb6fx-s / 8eMhYVZyBcs
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
