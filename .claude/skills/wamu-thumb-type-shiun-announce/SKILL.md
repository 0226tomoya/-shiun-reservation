# shiun 告知型

- 写真（LOOK・物撮り・コラージュ）を全面に。色は白黒だけ（グラデ・縁取り・黄色は使わない）。
- 見出しは**太い明朝**: NotoSerifJP 900（右に傾く回は skew -8）/ ShipporiMinchoB1 800 / ZenOldMincho 900。横 0.72〜0.95 の長体。白＋黒ぼかし影。
- 左上に小文字の「shiun」ロゴ、右上に細いセリフの英字「26 Fall 1st Collection」、下（中央）に「September 26th Sat. 10pm - Release」（EBGaramond / CormorantGaramond / PlayfairDisplay の細め、字間広め）。
- 細いペン字の和文は KleeOne 600（QeVJ はこれで 32→63 点）。
- 白い細枠（2px）や傍点を使うことがある。
- 発売は 22:00（10pm）。発売日・時刻は台本と照合（`shiun-product-credit`）。
