# メジャーの線と数字のアニメーション（データ入力風）

完成例は `editing/output/denim_measure/デニム股上股下_メジャー_v3_効果音のみ.mp4`。作るスクリプトは `editing/shorts/denim_measure/measure_anim.py`。

## 手順
1. **文字起こし**（faster-whisper large-v3、単語の時刻つき）。字幕のテロップは入れない（ユーザーの指示）。数字の言葉の時刻を拾う（例: 総丈 1.38 秒・100cm 1.98 秒）。
2. **映像で服の端を測る。** 1920×1080 のコマに 50px ごとの目盛りを描いて見る。暗い画素の範囲を行ごとに走査すると、股の割れ目（2 本の脚に分かれる高さ）が分かる。
3. **線を置く。** 総丈は服の左、部分（股上・股下）は右に置く。長さは服の実際の位置に合わせる（画面上の比と数字の比は一致しなくてよい）。
4. **見出しなど元の文字は一切触らない**（ユーザーの指示）。重ねる要素が見出しにかからないことを確かめる。
5. **書き出す。** `python3 measure_anim.py IN.mp4 OUT.mp4 --mute`。服の位置と時刻はスクリプトの先頭の値（WAIST・CROTCH・HEM、TOTAL / RISE / INSEAM の line・num）を変える。

## 見た目（シンプル）
- 墨色 (34, 34, 34) の 1 色だけ。書体は Noto Sans JP（見出し 500・30、数字 700・76、cm 500・34）。
- **線：** 太さ 3、両端に横線（幅 32）。目盛りは 5cm ごとに 8px、10cm ごとに 14px で、服の側に向ける。話し始めに上から下へ 0.55 秒で伸びる（easeOutCubic）。
- **股の高さ：** 股の点から右の線まで点線を引く。
- **数字：** データ入力風に 1 字ずつ打つ（0.075 秒ごと、数字 → cm）。
  - 打っている間は縦棒のカーソルが点滅し、打ち終わって 0.75 秒で消える。
  - 入力欄の下線（濃さ 110/255）が見出しと一緒に伸びる。
  - 0 から数え上げる動き（v1）より、データ入力風のほうが好まれた。

## 音
- **元の声はミュート**（`--mute`）。音は効果音だけにする。
- 効果音は合成する（手元に素材ファイルが無いため）。
  - 1 字ごとのキーのクリック（−22dBFS に 8dB 上げ）。
  - 線が伸びるときのごく薄い「シュッ」（−30dBFS に 8dB 上げ）。
- **打ち終わりの確定音（ピロン）は入れない**（ユーザーの指示。`ENTER = False`）。
- 効果音だけの wav も一緒に渡す（Final Cut Pro で差し替えられるように）。

## 気をつけること
- 書き出しで「No space left on device」が出ることがある。そのときは 670 コマ全部が入っているか（`ffprobe -count_frames`）と、音の長さを確かめる。容量が足りなければ、作り直せる派生ファイル（確認用の縮小動画・16kHz の音声）を消す。
- 進み具合はタスクプレビュー（`task-preview`）の `boards/ai-measure` に書く。
