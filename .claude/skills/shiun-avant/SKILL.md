# アバン

- 動画で一番伝えたいこと・いちばん共感される発言から（対談 A15 は最後の「コンプレックスがあると〜」を頭へ。離れた発言をつないでよい）。
- 知らない人が語る画には肩書きテロップ（「元チビデブハゲ」）。
- 出演者の態度が悪く見えるカット（足を組む・冷笑）から始めない。
- わむうが指定したフックのセリフから入る（「あ、牛乳とか飲むんですか？」）。
- 販促は案件っぽさを出さず結論から。
