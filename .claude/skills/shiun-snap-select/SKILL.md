# スナップの選定と色合わせ

- 全部を番号つきの一覧画像（40 枚ずつ）で見て、同じ画角ごとにグループに分ける（`editing/plans/A24_スナップ画角グループ.txt` の書き方）。
- 同じ画角は 3 枚以内。グループの前・中・後から、ピント（エッジの上位 2%）が一番鋭いものを 1 枚ずつ。
- 外すもの: ブレ、人やスタッフの写り込み、床やスタンドの見切れ。
- 厳選のときは画角 1 つにつき 1 枚。インサートに使いやすい画角（全体・横からのヒールの高さ・寄り・ソール・着用）を優先。
- 素材感の寄り: 等倍で革のシボとステッチが一番くっきり出ているもの（A24 は DSC09906）。
- 色: SNS 用高画質の完成画像（例 ローファー 02）の背景の明るさと色に寄せる（`editing/tools/snap_grade.py`）。
  明るさは最大 1.35 倍、色の偏りは各色 ±10%、黒は全色同じだけ。背景が 1/4 未満の寄りは、近い番号の写真の値を使う（服を背景と取り違えない）。
- 共有リンクは読むだけなので、Dropbox 内の移動は Mac 用の `.command`（JPG のみ・「選定済み」フォルダ）を渡す。送れるのは 1 ファイル 30MB まで。
