# 手書き風の注記

- YuseiMagic 400（白、size 45〜65、scale_x 0.8〜0.9）を**少し傾けて**（-20〜+15°、多いのは ±3〜10°）見出しの上・顔の横・右上に 1 つだけ。
- 文言は肩書きか口語の一言で、**必ず「!!」「!?」で終わる**: 「低身長男性限定!!」「低身長のカリスマが解説!!」「マジで気をつけて!!」「コレ買っとけ!!」「即完間違いなし!!」。
- 背景が明るければ黒、暗ければ白＋黒ぼかし。
- 例: 7Mrqw2dPfbo（「低身長男性限定!!」YuseiMagic・61.7px・-10°）
