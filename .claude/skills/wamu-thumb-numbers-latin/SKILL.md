# 数字・欧文

- 数字は和文より大きく。価格・BEST は欧文の極太（Montserrat 900 の斜体風）かディドン体のセリフ。
- 「¥2,990のコスパ最強ニット」のように価格を行頭に置き、「の」を小さく。
- 英字の飾り（2024-25 Winter / Spring、LOOKBOOK、SPECIAL EDITION）は細い筆記体かセリフで小さく添える。
- 縦書きの「!!」は縦中横にできない（今の道具の限界）。
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
