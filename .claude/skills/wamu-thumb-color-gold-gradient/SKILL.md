# 金グラデ

- `"fill":"linear-gradient(180deg,#a8761c 0%,#f5d26b 30%,#fff7d0 50%,#f9e39a 70%,#b8862b 100%)"` の系統（上下が暗い金・中央が明るい淡黄）。冬は水色系 `linear-gradient(180deg,#edfaff 0%,#bde4f6 50%,#8cceee 100%)`（LnmQ9GYPsHU の「冬」）。
- 茶黒の細縁＋右下の立体影、斜体（skew -6〜-8）、背景に集中線。
- グラデは行の箱にかかるので、縞の位置が字とずれたら line を 1.0 にする。
- runs とグラデを混ぜると暗くなることがある → かたまりごとに別レイヤー。
- 例: LnmQ9GYPsHU / yXbm2bU0Tis / 8eMhYVZyBcs / RZKetjK8amQ
