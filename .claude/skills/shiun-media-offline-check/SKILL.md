# メディアオフライン・画像の抜け

- 6 回指摘。2 分割の左（shiun ラベル付きの比較画像の枠）に集中: A22 コートの教科書 4:50・5:55、NG ファッション 2:49・6:09、A30 1:38、A17 3:31。
- 本人が右寄せで左を指差しているのに画像が無い（7/17 11:23）。
- 書き出す前に FCP でオフラインの数が 0 か、素材を移した後は比較インサートと 2 分割を全部見る。
- XML を渡すときは、置いてもらう素材（公式サイトの画面など）の場所を必ず書く。
