# erase の調整

- 既定は「範囲の中で、描いた文字の色に近い画素」を消す。tol（色の近さ）を背景に合わせる:
  - 白い壁・白シャツ・空・紙袋のベージュの近く: **tol 7〜16**、色は必ず明示（`"colors":["#ffffff"]`）
  - 暗い背景の白文字: 25〜30
- 色を指定しない矩形や tol 26〜30 の白は、シャツや壁を丸ごと消して点を大きく下げる。
- ロゴ・帯は `"full":true`。斜めの帯・文字列は `"poly"`。
- 矩形の端が文字の端と同じだと消し残る → 少し広げる。
- `"by":"layers"` は描いた形で消すので採点が甘くなる（今は公平に直したが、なるべく使わない）。
- 黒縁・ぼかし影は元の文字側に入らないので、太くすると損。
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
