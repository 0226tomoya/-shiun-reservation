# トップスの画角（A18 の修正）

- トップスの紹介中は全身の引きを使わない。拡大して、ラックの服と着用した上半身を大きく（膝上まで、足元は切る、椅子は端に少し）。
- 全身の引きはパンツ・シューズ・シルエットの場面に使う。
- 商品テロップの位置は変えない。
