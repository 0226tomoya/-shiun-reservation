# コラボ

- 相手チームにも確認してもらう。相手のイメージに関わる話（銭湯のくだり）は切る。
- 街頭インタビューは「誰が出るか」が見どころ。サムネや冒頭でネタばらししない。公開の順番にも気をつける。
- 他ブランドの商品名・価格は先方の担当者に確認。
