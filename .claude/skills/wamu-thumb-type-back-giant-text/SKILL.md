# 人物の後ろの巨大文字（3 層）

- 層: 背景の巨大文字（濃灰か白、size 600〜720、1 文字ずつ）→ 人物 → 手前の白見出し。
- 人物を文字の前に戻すのは仕様の `"front"`（人物の輪郭の多角形）。例 h3pdi0qvi94（82 点）の「感謝」: size 720、scale_x 0.907、front は人物の輪郭 19 点の多角形。
- 2025 年春ごろに繰り返し出る（担当 10）。
- 例: h3pdi0qvi94 / HVmj2KwLjxM / IGI3WXz1ymg
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
