# インサートの量

- **多め**が好まれる。同じ素材の使い回し OK（わむう「端から端まで見る人は少ない」）。
- 撮った着用インサートは必ず使う（見落としで指摘）。着用パートは外で撮った全身の着用インサートを「入れまくる」。撮ったコーデ（3 パターン）は全部。
- 発売が近い商品は寄りで。在庫のあるアイテム中心に新作もチラ見せ。
- 素材が無い所は AI 生成画像のインサート（何度もほめられた）。

## A24 修正版から（10/12）で改めた所
- 使い回しは OK ではない。60 秒以内の再使用は修正版でほぼ 0（6 回）。使い回すのは商品カードの複合だけ（1 商品 3 回まで） → shiun-insert-material-mix。
- 量を埋めるより、話している部位が見える素材を選ぶ。E1 はインサート秒数の 50% 以下。
