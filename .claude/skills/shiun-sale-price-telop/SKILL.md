# SALE の価格

- 「元の価格 → ○% OFF → SALE 価格（赤・大きく）」の 3 段（藤田さんの参考画像）。景品表示法の二重価格表示に注意。
- 告知動画には SALE の期限（「〜1/31まで」）を入れる。最終日の販促はショート・ストーリーで。
