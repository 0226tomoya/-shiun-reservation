# 色・画・音（詳細は `editing/knowledge/編集ルール集_わむうsns_1年分.md` の 3 章）

- 色: ホワイトバランスを**少し暖色**、彩度は落ち着かせる（わむうの VSCO の見本。白い壁が青く見えない程度）。カットどうしの色の跳びをそろえる。
- 同じ商品を何人かが着る場面は**わむう側の色にそろえる**。ボタン・金具の色は実物（例: 黄みのあるアンティークゴールド）に合わせ、違えば静止画で差し替え。
- わむうの映像だけ上下の余白を付けない・引きすぎない（モデルと並べるとスタイルが悪く見える）。
- 背景は自然光の「家っぽい」部屋、物を置きすぎない。
- 音: **声優先で音楽小さめ**。BGM は全編（喋っていない所で無いと目立つ）。シュールなショートは BGM・効果音なし。カットはジェットカット、粗編集で音量をそろえる。
