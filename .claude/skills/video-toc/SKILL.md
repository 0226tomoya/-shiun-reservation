# 動画の目次作成 (fcpxml のピン → YouTube チャプター)

## デフォルトの形式

```
00:00 OP
<1本目のピン> 1人目
<2本目のピン> 2人目
...
<最後のピン> ED
```

- 先頭には必ず `00:00 OP` を付ける (YouTube のチャプターは 00:00 始まりでないと有効にならない)。
- **一番最後のピンは ED** (そこから ED ムービーに繋がる)。それ以外のピンに時間順で `1人目`, `2人目`… と番号を振る。
- 時刻はプロジェクトのタイムライン上の位置で、秒未満は切り捨て。1時間を超える動画は `h:mm:ss`。

## 手順

1. アップロードされたファイルのパスを確認する (例: `/root/.claude/uploads/.../xxx.fcpxmld.zip`)。
2. スクリプトを実行する (zip のままでよい。展開は一時ディレクトリで行われる):

   ```bash
   python3 -I .claude/skills/video-toc/scripts/fcpxml_toc.py "<入力パス>" --debug
   ```

   - `--label "{n}人目"`: 見出しを変える ({n} が通し番号。例: `"{n}組目"`)
   - `--project <名前>`: ライブラリ内にプロジェクトが複数ある場合に指定
   - `--no-op` / `--no-ed`: OP / ED を付けない
3. 確認する:
   - stderr に出るピンの総数と、ユーザーが言った人数 + 1 (ED) が合うか。合わなければ黙って調整せず、`--debug` の出力 (マーカー名・クリップ名) を添えてユーザーに確認する。
   - ED が全長の終わり近くにあるか。
4. 結果をコードブロックで返す (`--debug` の括弧部分は除く)。

## 仕組みのメモ

- マーカーは素材クリップ側 (マルチカムクリップ等) に付いているため、同じマーカーが XML 内に何百回も出てくる。スクリプトは project の spine を辿り、各クリップの使用範囲 (`start`〜`start+duration`) に入っているマーカーだけを `offset` を使ってタイムライン時刻に変換する。
- 素材内のマーカー番号 (「マーカー 1」など) とタイムライン上の順番は一致しないことがある。順番は必ずタイムライン時刻で決める。
- 複合クリップ (ref-clip) の中身 (resources 側) に付いたマーカーは拾わない。ピンが足りないときはそこを疑う。
