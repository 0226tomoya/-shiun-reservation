# 文字起こしの時刻は音で確かめる

- A24 の比較で、粗編集のクリップを通して素材の時刻に移した文字起こし（words_src）が、実際の音と 30〜85 秒ずれていた。ずれ幅は一定ではなかった。カットの分析の「削った発言」の文字と型分けは、ほぼ全部まちがっていた。
- 原因の候補は 2 つ。文字起こしをしたタイムラインと、時刻の移し先のタイムラインが別の版だった。または、粗編集の中に素材の順番を入れ替えた所があった。
- **使う前の確かめ方**: 文字起こしの中から、はっきりした語（数字・商品名）を 3〜5 個選ぶ。その語の素材の時刻の前後 2 秒を切り出して聞く（または whisper にかける）。3 つとも 0.5 秒以内で合っていなければ使わない。
- **確実な作り方**: 書き出したプレビューの音を faster-whisper で起こし、プロジェクトのクリップの対応（タイムライン → src）で素材の時刻に直す（A24 では `telop/words_asr.json`）。ピンマイクの音とも合っていることを確かめた。
