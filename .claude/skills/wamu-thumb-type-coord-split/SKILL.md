# コーデ縦分割型

- 4〜5 枚の全身コーデ写真を縦の帯で並べ、中央に本人。
- 文字は下 1/3 に白の特大 1 行（または中央に白ゴシック 2 行）。
- 「〇コーデ」「最強コーデ5選」「大人のキレイめカジュアル」。
- 分割の境目に緑・黒の線が出ないよう、パネルは少し大きめに拡大（Slack の指摘）。
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
