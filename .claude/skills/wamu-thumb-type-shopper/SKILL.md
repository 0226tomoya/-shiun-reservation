# 紙袋（ショッパー）型

- 人物が UNIQLO / GU の紙袋を持ち、袋にロゴを合成して大きく見せる。
- 紙袋に印刷されたロゴは写真の一部なので消さない・描き直さない。
- 金・白の文字は紙袋のベージュと色が近いので、erase の tol を 7〜12 に下げる（`wamu-thumb-erase-tuning`）。
- 例: xq6q… / kipV… / w_Pd… / RKzA…（担当 10 のメモ）
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
