# ？のシルエット

- 黒く塗った服のシルエット（写真のまま残すことが多い）に、大きな「？」を重ねて中身を見せない。
- 「？」は太いセリフ（ZenOldMincho 900、scale_x 1.1〜1.15）。白・灰・黒。線だけの「？」は `"hollow":true`。
- 例: d57LRGuyX2Q（81 点。? を ZenOldMincho 900・133.6px・scale_x 1.141 で 4 つ）/ QKeAHuX2-wk / Pl2neyV41qQ
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
