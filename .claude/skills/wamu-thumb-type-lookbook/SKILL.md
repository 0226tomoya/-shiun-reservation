# LOOK BOOK 型

- 英字タイトル（LOOK BOOK / CLOSET TOUR / 2024-25 WINTER MEN'S FASHION）をセリフ（PlayfairDisplay 700〜900・CormorantGaramond・Cinzel）か細い筆記体（GreatVibes・Allura・Parisienne）で。
- 黒文字＋黒の細枠＋右上に shiun の角ロゴの版と、白文字＋写真コラージュの版がある。
- サブに日本語（「UNIQLO・GU を使った 33 の冬コーデ!!」）を斜体の手書き風で。
- 細い英字は 1〜2px のずれで形の一致が大きく落ちる（iou_tol も見る）。
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
