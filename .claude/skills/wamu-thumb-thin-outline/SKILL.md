# 縁は細く

- 形を合わせるために同じ色の縁を 6px・13+17px と太らせると、字の中（ふところ）が潰れて見た目も点も落ちる。
- 縁は **2px 前後** にして、太さは書体の weight と大きさで合わせ直す → +5〜+13（5周目 mid_0）。
- 本当に縁がある字は、拡大して縁の色（白縁か黒縁か）を確かめる。逆に読んでいる例が多い。
- erase の色リストに縁の色（白縁なら白）も入れる（入れ忘れで +4.7 取りこぼした例: OvZs）。
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
