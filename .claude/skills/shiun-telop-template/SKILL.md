# テロップの型

- 型は `editing/components/role_templates_A19.fcpxml`（無いものは A18）。`build_lineup.apply_template` で作る。手で値を書かない。
- 型ファイルには、テロップ本体のエフェクトと中のフィルタ（フェードイン・アウト）のエフェクトの定義が両方要る。
  無いと型の文書の ID のまま残り、A24 では同じ番号の写真を指して FCP が読み込めない（r383 の事故）。
- 字幕: 1 行は 位置 `1 -483.734`、2 行は `1 -440.734`（43px 上げる）。字間（kerning 1.6）は改行と最後の 1 文字以外に付ける。
- 行の間隔 = 0.75 ×（この行の一番大きい文字＋次の行の一番大きい文字）＋ lineSpacing。位置は 1 行目に付く。
- 縁取り・影は付けない（ユーザー指示・修正 30）。`apply_overrides` の `no_stroke`。
- 確認: `fidelity_full.py FLAT A19.json A23.json` で違いが縁取りだけであること。位置は役割ごとに過去データにある値かを確かめる（A24 v24 で 0 件）。
- 字幕の頭と終わりは本編の編集点に合わせる（A19 は 100%）。`apply_overrides` の `snap_subtitles`（前の編集点を優先して出し、後ろの編集点まで残す）。
- 字幕の文字は、そのとき話している内容の要約。`audit_inserts.py` で発言との一致率が 0.3 未満のものが 0 件であること。
- 量の目安（1 分あたりの字幕）: A19 2.0・A23 3.0・A18 2.9。

## 過去のラインナップ 5 本の完成データ（FCP ライブラリから直接、`tools/fcpevent_titles.py`）
- アーカイブの .fcpbundle の zip（イベント/プロジェクト/CurrentVersion.fcpevent）を範囲読み（remote_zip.py）で取り出して読む。
  A19 のライブラリの本編は公開動画（A19 mp4、1570.49 秒）と同じ長さで、テロップの時刻・位置もフレームで一致を確認済み。
  ライブラリの ozml の「サイズ」は FCPXML の fontSize と同じ単位ではない（字幕: ozml 40 ＝ 画面上 32）。大きさは FCPXML の値を使う。
- 5 本（A10・A21 2 月・A21 3 月・A18・A19）で同じ型: 字幕 Klee-Medium x≈0・y≈-484、商品名ラベル Masqualero 左上 (-850, 440)、
  身長別 (-290/310/-870, ≈405)、右下の英単語 (Silhouette 870 / Material 700 / Color 750 / Wash 760, y -480)、色の注記 (860, -510)。
- 字幕の行: 1 行 380 枚はすべて全角換算 45 文字以内。2 行 55 枚はすべて y≈-436〜-442（2 行を 1 行の位置に置いた例は 0）。
  → `apply_overrides` の `subtitle_layout`（45 文字を超えたら真ん中に近い読点で 2 行、2 行は `1 -440.734`）。
- 右下の英単語は字幕と同じ頭・同じ長さで出す（同じ話題が続くときは 2 枚にまたがることもある）。全字幕に付けるわけではない（約半分）。
  5 本の合計: Design 38・Material 34・Silhouette 31・Detail 13・Color 11・Wash 4。
  Detail は小さな部品（リブ幅・ジップ・ボタン・ポケット位置・ウエスト）、Design は元ネタ・全体の作り（〜年代・踏襲・ミニマル・仕様）。
- 字幕の文言は話し言葉の書き起こしではなく、商品説明の要約（例: 「経糸44番手、緯糸50番手の単糸を使用した綿100%の素材」）。
