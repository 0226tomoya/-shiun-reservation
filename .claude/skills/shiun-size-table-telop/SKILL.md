# サイズ表

- EC と同じ表を元に、**小数点以下も丸めない**（2026-05〜）。食い違うとブランドの信用を落とす（わむう）。
- 項目名は WYM の書き方「着丈(ネックポイントから)」。
- 前後差がある服は前・後ろ（・脇）の着丈を全部書く（数字だけだと長いと誤解される）。
- 幅のあるウエスト（77〜83）が片方しか無いときは企画（中森さん）に確認。
- わむうの着用サイズは M（26Fall1st）。モデルの身長は元データで確認（ひびきくん 165cm）。
