# 仕上げのカット（粗編集 → 完成）

- A19: 粗編集 1623 秒 → 完成の本編 1395 秒（228 秒・14% 切る）。丸ごと削除 139 本（40 かたまり・197 秒）、頭を削る 18（中央値 0.42 秒）、終わりを削る 25（中央値 0.53 秒）。
- A23: 粗編集 1935 秒 → 本編 1732 秒（203 秒・10.5%）。丸ごと削除 140 本（36 かたまり・191 秒）。完成で足した素材は 0。
- 調べ方: `tools/fcpevent_spine.py`（ライブラリの粗編集を取り出す）→ 粗編集どおりに音声をつなぎ文字起こし → `tools/finish_cut_diff.py`。
- A24 の粗編集（ユーザーの XML）は【カット済】ライブラリとほぼ同じ（1253 本中 1244 本一致）＝仕上げのカットはまだ入っていない。

## 切るもの（A19 で確かめた。A は A19 の例）
- A 差し込みの直前の合図: 「こちらです。どうぞ。」（身長別比較の前）、「で、こちらですね」
- B 言い直し・言葉探し: 同じ文をすぐ言い直す前のほう、「〜くんねんけど」などの言いかけ、単独の「で、」「まあ、」
- C 独り言・反応: 「いいですよね」「襟ですよ、襟」「まあ、そのほうがよく売れるしね」「かっこいいですね」
- D 裏話・身の上話の脱線: スタッフの数・会場費・「利益もっと欲しい」・結婚の順番・ブランドの決まり文句（「良い生地を良い加工で…ご安心ください」）
- E 言ったことの言い直しのまとめ: 「なので低身長でも安心して着れるんですね」「1 年のうち 300 日ぐらい着れる」
- F 説明しすぎ: 季節を全部挙げる、再販の納期の細かい話、他社の値段（「3 万 4 万」）
- 商品の紹介の頭の重複: 「まずはね、こちらを紹介していこうと思います」「今僕が着ているブルゾンですね」→ 商品名から入る

## 残すもの
- 素材・作り・シルエット・サイズ・価格・販売実績・発売日などの事実
- テーマにつながる個人の話（例: 子供ができて紐靴を履く時間がない → ローファーが楽）。脱線の部分だけ切る

## 進め方
1. 粗編集の文字起こしを読み、上の決まりで切る候補に印を付ける（量の目安は 10〜14%）。
2. 1 つ前の回で、正解を見ずに予測 → 実際の仕上げと比べて当たり・外れを数える（決まりを直す）。
3. 切る位置は `apply_cuts.py --mic`（スキル shiun-cut-audit）で声に合わせる。
