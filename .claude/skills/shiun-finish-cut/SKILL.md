# 仕上げのカット（粗編集 → 完成）

## 事実（過去の回の実測）
- A19: 粗編集 1623 秒 → 完成の本編 1395 秒（228 秒・14% 切る）。丸ごと削除 139 本（40 かたまり・197 秒）、頭を削る 18（中央値 0.42 秒）、終わりを削る 25（中央値 0.53 秒）。
- A23: 粗編集 1935 秒 → 本編 1732 秒（203 秒・10.5%）。丸ごと削除 140 本（36 かたまり・191 秒）。完成で足した素材は 0。
- 調べ方: `tools/fcpevent_spine.py`（ライブラリの粗編集を取り出す）→ 粗編集どおりに音声をつなぎ文字起こし → `tools/finish_cut_diff.py`。
- A24 の粗編集（ユーザーの XML）は【カット済】ライブラリとほぼ同じ（1253 本中 1244 本一致）＝仕上げのカットはまだ入っていない。

## 確かめた結果（A19 の決まりで A23 を予測 → 実際と比べた）
- A23（公開版「靴なし」・靴以外）: 実際に切った 111 発言・123 秒（10.3%）／ 予測 290 発言・287 秒 → 当たり 44 秒。適合率 15%・再現率 36%。
- A19 で切っていた「反応・言い直しのまとめ・脱線・裏話・説明しすぎ」は、A23 ではほとんど残っていた。
  → 発言の中身の決まりで自動で切ると、切りすぎて、しかも外す。**中身で切る仕上げのカットは自動でやらない。**
- 2 つの回で必ず切っていたもの（自動で切ってよい）:
  1. 編集者への指示（「もらってたら共有します。もらってなかったらカットで」「台本よりも僕が言った順番でお願いします」）
  2. 差し込み（身長別比較・試着会の感想）の直前の「どうぞ。」
  3. 入っていない差し込みへの言及（A23 では試着会の感想の動画を入れなかったので「試着会の感想をご覧ください」を全部切った）
- A23 で切っていたが A19 の決まりに無かったもの（回によって切る。ユーザーに確かめる候補）:
  過去の商品の具体的な販売足数、「安っぽく見えない」の言い訳、他のブランドの服の説明、サンプルの注意書きの繰り返し。
- 量の目安だけは安定している: 2 つの回とも粗編集の 10〜14%、かたまり 27〜45 個。

## 進め方
1. 自動で切るのは上の 1〜3 だけ。素材の時刻で `plan.edits.src_cuts` に書く（タイムラインの時刻のずれに影響されない）。
2. 中身で切る候補は、ユーザーに一覧で見せて決めてもらう（勝手に切らない）。
3. 切る位置は `apply_cuts.py --mic`（スキル shiun-cut-audit）で声に合わせる。
4. 新しい回の粗編集と完成が届いたら、同じ比べ方（`fcpevent_spine.py` → 文字起こし → `finish_cut_diff.py`）で決まりを足す。
