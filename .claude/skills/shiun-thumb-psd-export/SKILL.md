# PSD で渡す（psd-tools の落とし穴と確かめ方）

## 必ずやること
1. **全体のタグブロックは元のバイトに戻す。** psd-tools は保存し直すだけで、スマートオブジェクトの埋め込みデータ（lnk2）の末尾（contentID）を落とす。その結果、Photoshop で「互換性がありません」と出て開けない（A25 v2 で起きた）。
   - 戻し方は `editing/thumbs/a25_psd.py` の `global_blocks`。
   - 確かめ方: 何も変えずに保存し直したものが元とバイト単位で同じか比べる。違えば、どのブロックが変わったかを見る。
2. **足すレイヤーは `PixelLayer.fromarray(RGBA の配列)` で作る。** `frompil` は RGB の PSD だと、透明を「不透明な画＋マスク」にしてしまう。
3. **レイヤー ID を振る。** 全レコードの最大の次から振る。グループの終わりの区切り（`</Layer group>`）も ID を持つので、`descendants()` だけで最大を取ると重なる。
4. **日本語のレイヤー名は `name` で付ける**（Unicode の名前欄に入る）。古い名前欄は英数字だけにする。
5. **元の文字レイヤーは打ち直せるまま残す。** 動かすときは画と変形行列を一緒に変える。
   - 変形行列は `TYPE_TOOL_OBJECT_SETTING.transform`。xx・xy・yx・yy に倍率をかけ、ty を新しい上端に合わせる。
   - 画は `fromarray` で作った仮のレイヤーの channel を移す。やり方は `a25_psd.py` の TITLE_K のところ。
6. **元の要素は消さずに非表示で残す**（元の大きさの靴、元の Coordinate、白い点が付いたままの人物）。名前に「元」と付ける。
7. **新しい文字は画のレイヤーにする。** psd-tools では打ち直せる文字レイヤーを新しく作れない。名前に書体・大きさ・字間を書いておく。

## 確かめる（渡す前に全部）
- ID の重なりが 0 であること、マスクの付いたレイヤーが 0 であること。
- スマートオブジェクトのデータ（lnk2）が元とバイト単位で同じであること。
- `node editing/thumbs/psd_tools_js/check.js X.psd` … 別の読み込みライブラリ（ag-psd）で読めること。node_modules が無ければ作業用フォルダで `npm i ag-psd@20` を入れてから使う。
- psd-tools で合成し直して、PNG の完成版との差を見る（平均 3〜4 なら粒子の差だけ）。合成した画像は自分の目でも見る。
- ここには Photoshop が無いので、開けるかは直接確かめられない。最初の 1 回はユーザーに開けたかを聞く。
- 開けなかったときの予備: `node editing/thumbs/psd_tools_js/write.js 層のフォルダ OUT.psd 合成.raw` で、全部画のレイヤーの PSD を一から書く。文字は打ち直せなくなる。
