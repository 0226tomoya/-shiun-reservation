# まず比較画像を見る

ずれの原因はほぼ 3 つ:
1. **1 行のまま描いて字間がずれる**（No.1 の「1」が浮く、「シャ」と「ツ」の間が空く、「って」が潰れる）→ 1 字ずつに分ける
2. **色・縁を逆に読んでいる**（白縁と黒縁、黒字と白字）→ 拡大して読み直す
3. **斜体を直立で描いている** → skew を付ける
- 見落としやすいもの: 見出しの後ろの暗いグラデ帯（NRrV +4.7）、front の付け忘れ、erase の縁の色。
- 字間の広い小さい行は 1 字ずつ、元画像の列から取った矩形に合わせる。
詳細は `editing/knowledge/サムネの決まり_わむう2年分.md`、再現の仕様は `editing/thumbs/specs/ID.json`（点数は `editing/thumbs/summary.tsv`）。
