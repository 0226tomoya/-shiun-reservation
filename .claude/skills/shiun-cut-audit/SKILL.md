# 編集点を音声で決めて確かめる

- 素材の時刻: マルチカム（mc-clip）の `start` はピンマイク音声（調整済み wav）の時刻と同じ。
- 声の判定: 10ms ごとの音量で、ノイズの床（下から 10%）+14dB 以上を声とする。
- ユーザー（粗編集）の切り方が基準: 編集点の無音（前の終わり＋次の頭）は中央値 0.13 秒・90% で 0.25 秒・最大 0.56 秒。
  粗編集そのものの編集点（`audit_cuts.py` で 280 件「疑い」が出るのはユーザーの詰めた切り方）は直さない。
- 自分が作る編集点の決まり（`apply_cuts.py --mic`）:
  - 前のカットの終わり = 言い終わり＋0.10 秒。次の発言の頭が 1 コマでも入っていたらその前まで戻す。
  - 言い終わりがそのカットより前（前のカットの中）なら、そのカットの頭から切る。
  - 次のカットの頭 = 言い始めの 0.08 秒前。粗編集のカットの頭ちょうどならそのまま（前へ広げると切ったはずの発言が入る）。
- 確認: `audit_cuts.py EDIT PINMIC OUT.json` を粗編集にもかけ、粗編集にない編集点（＝自分が作ったもの）だけを見る。
  `tail_cut`/`head_cut` が False、無音が 0.05〜0.3 秒なら合格。疑いがあれば 20ms ごとの音量を並べて目で確かめる。
- 時刻で指定した修正（plan.overrides）は `base_v1` から素材の時刻で写すので、編集点を直しても当て直しは不要。
