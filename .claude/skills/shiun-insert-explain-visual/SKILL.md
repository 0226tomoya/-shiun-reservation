# 話を画で見せる

- 「脚長効果」→全身の着用、「ディテール（地襟・ウエストベルト・裏地）」→物撮りか寄り（暗く小さいと伝わらない）。
- 股上・股下→パンツの画像で場所を示す。サイズの話の間は shiun のサイズ表を出しておく。
- Q&A の数値トーク（股下 70〜72cm）を顔アップだけで流さない。
- 素材の違い（スムース／シュリンク）→接写にラベルを付けて 2 分割。
