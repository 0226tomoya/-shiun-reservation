# 黄

- 黄 #fce207 / #ffe600 / #fff000 前後（縮小表示では色を見間違えるので画素で測る）。
- 結論の 1 語か数字だけ黄、または煽り型の大見出しを丸ごと黄（「絶対 買い」）。
- 影は黒の弱いぼかし、黒縁を付けるのは赤・黄の強調文字だけ。
- 差し色は 1 枚に 1 色。
