# ショート（詳細は `editing/knowledge/編集ルール集_わむうsns_1年分.md` の 7 章）

- **音なしでも分かる**ように。話す人が複数なら人ごとにテロップの位置か色を変える。画面外の声は吹き出しテロップを声の側に。紹介ラベルは縦書きの小さい白文字を人物の横。
- 相手役は背中・肩が見えるクロップ。凝ったモザイクよりズームで外す。
- 商品が出たら空いた所に商品画像＋詳細。
- 冒頭のつかみを強く、前置き（「詳細は」）なし。導線ショートは上部に「詳細はYouTubeから」＋本編のテーマ。
- タイトルは流れとオチが一行で分かる自然な日本語。
- 声優先で音楽小さめ（曲の指定があれば従う）。シュールな回は BGM・効果音なし。
- リリース前の商品は社内で作る。
