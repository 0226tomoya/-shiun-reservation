# 仮置き・書き方のチェック

- 修正版には「座布団01_07」で「(追加予定)わむうスナップ／4人スナップ」の仮置きが 7 本ある。スナップ写真を後で入れる場所の印。このまま書き出すと事故になる。
- **書き出す前に、「(追加予定)」「後ほど」「仮」を含むテロップが 0 本か確かめる**。残っていたら止める。
- 警告にするもの:
  - 説明テロップの「。」「僕」「超」
  - 余分な空白
  - EC の文から作った字幕の脱字（修正版にも「少シャープ」がある）
- 写真がまだ無いときの仮置きは座布団の型で作り、TODO マーカー（「あれば〜」）と組にする（shiun-export-project-only）。
