# 目次・タイムスタンプの作り方

1. 書き出した FCPXML（.fcpxmld の中の Info.fcpxml）を受け取る。zip なら作業用の空フォルダに展開する。
2. `python3 editing/tools/fcpxml_chapters.py Info.fcpxml` を実行する。
   - 出力の列は「時刻・秒・ピンの名前・付いているクリップ」。
   - ピンはクリップの中の時刻で打たれているので、ツールが本編のタイムラインの時刻に直す。
3. 1 行目は必ず `0:00 OP`。
4. ピンごとに 1 行。名前はピンの名前（「2.カーコート」）を使わない。その商品の商品名テロップの **英字の 1 行目**（「SOFT GRAIN CAR COAT」）を、大文字・記号もそのまま使う。
   - 商品名は、XML の title の中にある「英字の行＋改行＋Color : …」の 1 行目。
5. 最後のピンが ED なら `ED`。
6. 時刻は秒未満を切り捨てて `分:秒` にする（例: 79.11 秒 → 1:19）。1 時間を超えたら `時:分:秒`。
7. 形式は次のとおり。保存先は `editing/<回>_timestamps.txt`。
```
0:00 OP
1:19 COW LEATHER LOAFER
10:32 SOFT GRAIN CAR COAT
...
33:27 ED
```

## ピンの打ち方（A24 の修正版と比べて確認、10/12）
- ピン（チャプターマーカー）は**各商品の最初の本線の mc-clip** に打つ。位置は**アイキャッチ明けの最初のフレーム**。名前は「1.ローファー」〜「6.ベルト」と「ED」（番号.商品の短い日本語名）。
- 0:00 の OP には打たない（目次の 0:00 OP は手で足す）。こちらの版と修正版で同じ打ち方だった。
- 試着会など商品パートの中の差し込みにはピンを打たない（目次ではその商品に含める）。
- 普通のマーカー（TODO の「あれば〜」など）は目次に入れない。ツールは chapter-marker だけを拾う。

## 確かめること
- ピンの数と商品の数が合っているか（足りなければ、商品名テロップが最初に出る時刻を候補として出す）。
- 時刻が増える順に並んでいるか。
- 商品名の表記が、テロップと 1 文字も違わないか（C/W・FLAT-FRONT など記号も）。

例: A24（`editing/A24_timestamps.txt`）
