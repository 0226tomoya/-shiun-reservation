# 修正の読み方

- わむうの修正（LINE など別ルートもある）が最優先。それ以外に指摘が無ければ OK。
- 「どこを・なぜ・視聴者にどう感じてほしいか」で読む。「今回必ず対応」「提案・相談」「できれば」「今後の撮影」を混同しない（げんじ 9/12）。
- 最新の訂正を優先、分からない数値（身長・サイズ・時刻）は推測で埋めない。
- 指摘の中身はスクショだけのことが多い → 画像を必ず開く（赤丸・黄色の書き込み）。
- 入れたら `shiun-overrides` で plan に書き、ビルドし直す。
